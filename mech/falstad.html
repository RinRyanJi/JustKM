⚡ Falstad：在瀏覽器裡看電流怎麼走

Circuit Simulator 的介紹、操作，和它背後在解什麼。給還沒碰過硬體的人。

給硬體小白 不用安裝 正體中文介面 先看一條迴路

打開 全螢幕版 就會看到一條已經在跑的 LRC 電路。這是 Paul Falstad 寫的電路模擬器，原本是 Java applet，後來由 Iain Sharp 移植成瀏覽器裡的 JavaScript（circuitjs1）。不用安裝。離線版在首頁的 Standalone (offline) versions。介面可依系統語言出現正體中文。

① 畫面在說什麼

下面的顏色，是作者在 操作說明 和 首頁 寫的。正體中文對照來自程式自己的語言檔 locale_zh-tw.txt。你的畫面若寫得不一樣，以畫面為準。

四個顏色各一句。這不是示波器，也沒有假的刻度。
  • 滑鼠停在元件上，角落會寫出這個元件現在的狀態。作者的說明寫在視窗右下角。
  • 右鍵（Mac 用 control-click）選 Edit（編輯），改電阻、電容、電壓、波形。
  • 下方圖是示波器。電壓綠色、電流黃色。電流可能被電壓蓋住。右鍵元件選 View in Scope（在示波器中檢視）。
  • Simulation Speed（模擬速度）：模擬算得快或慢。電路裡沒有電容、電感、或會隨時間變的電源時，它沒有作用。
  • Current Speed（電流速度）：只改黃點動畫的快慢，不改變算出來的電流。這一點 Clemson 的教學也特別提醒。
  • 點開關就切換。Reset（重置）把電路拉回一個合理狀態。Run/Stop（執行／停止）暫停。
  • Circuits（電路）選單是現成範例，載入後可以改。每一則在做什麼，見 範例逐則說明。

② 畫第一條電路

步驟跟著 keejko 的正體中文走法（他用的是離線版）。選單的中文以程式語言檔為準：keejko 把電壓錶那一層寫成「輸入和輸出標籤」，語言檔寫的是「輸出和標籤」（Outputs and Labels）。快捷鍵兩邊一樣。

  1. 檔案 → 建立新的空白電路（File → New Blank Circuit）。
  2. 導線：繪製 → 加入導線（Draw → Add Wire），或按 w。在起點按住拖到終點。
  3. 電阻：繪製 → 加入電阻器（Draw → Add Resistor），或 r。
  4. 電池：繪製 → 輸入和電源 → 加入直流電壓源(二端)（Draw → Inputs and Sources → Add Voltage Source (2-terminal)），或 v。一端電壓源（加入直流電壓源(單端)，Add Voltage Source (1-terminal)）的另一端是接地，官方說明如此。練習用二端這顆。
  5. 電壓錶、電流錶：繪製 → 輸出和標籤 → 加入電壓錶／加入電流錶（Draw → Outputs and Labels → Add Voltmeter/Scope Probe／Add Ammeter）。
  6. 按住空白鍵再用左鍵，才能選取或拖曳。Alt-拖曳移動整張圖。滾輪縮放。
  7. 右側 執行／停止（Run/Stop）。keejko 的離線版把這顆按鈕放在右側；你的版面若不同，找「執行／停止」這幾個字。
  8. 右鍵 Edit（編輯）改數值。官方：直流電壓源可改成 DC、AC 正弦、方波、三角、鋸齒、脈衝；不是 DC 還能改頻率和 DC offset。語言檔裡對得上的字是正弦波、方波、三角波、鋸齒波、脈波，以及頻率、直流偏壓（DC Offset）。

要接地：繪製 → 輸入和電源 → 加入接地（Add Ground）。灰色那一點就是地。

練習，用歐姆定律算，不是跑過模擬抄來的讀數。電池 5 V、電阻 1 kΩ，串成一個迴路，並接地。電流應約 5 mA。滑鼠停在電阻上，用角落的數字對這個數。若差很多，先看是不是沒接成封閉迴路，或電壓源被短路。

Clemson 的入門 PDF 補了兩句。Current Speed 純視覺，不影響模擬結果。游標讀到的電壓差是絕對值，跟該元件的示波器極性無關（原文是 oscilloscope polarity，不是另外一支探棒）。那份 PDF 的介面比較舊，讀數框寫在左上角；作者現在的說明是右下角。位置以你打開的畫面為準。Clemson tutorial 1 PDF

③ 存檔、分享、匯出

  • Ctrl+S，或檔案 → 儲存（File → Save）。存的是純文字，不是圖片。
  • File 選單可把電路匯出成連結來分享，連結可以縮短。正體中文是檔案 → 匯出連結…（Export As Link...），縮短是建立短網址（Create short URL）。
  • 檔案選單有匯出圖片(PNG)…（Save As Image...）、匯出向量圖(SVG)…（Save As SVG...）。keejko 也寫了這兩項。
  • File → Recover Auto-Save（檔案 → 回復自動儲存的檔案）可救回關掉視窗弄丟的電路；不行就 Edit → Undo（編輯 → 復原）。
  • File → Find DC Operating Point（檔案 → 尋找直流工作點）：電路要很久才穩態時，這個選項會立刻把電容充到該有的狀態。

④ 它在解什麼

這段照專案自己的筆記講，路徑就是 pfalstad/circuitjs1 的 INTERNALS.md。這個網址打得開，不是改放別的檔。用白話，不展開電感怎麼進矩陣。

每個接點有一個未知的電壓。接地那點被訂成 0，不然整張電路可以一起上下平移，方程式沒有唯一解。筆記的講法是：接地若還留在矩陣裡，矩陣會 singular，因為每一點都可以一起加同一個電壓，答案就不只一組。

方法叫 modified nodal analysis。電阻放進矩陣時用的是電導（1/R）。電壓源要多一列，強迫兩端電壓差等於你設的值，同時多一個未知數：它送出的電流。

解出來的是各點電壓，電流再由此算出。線性電路可以先做 LU 分解，每一步只更新右邊。二極體這類非線性零件要在每一步反覆解，直到收斂。

時間是一小步一小步往前。Edit → Other Options（編輯 → 其他選項…）裡的 time step（時基）愈小愈準、愈慢；頻率高的電路需要更小的 time step。

⑤ 它會罵你的幾句話

英文是作者操作說明裡的句子。括號裡是語言檔的正體中文，方便你對畫面。電壓源那一句，說明書寫 Voltage source loop with no resistance；語言檔的英文鍵稍長，是 Voltage source/wire loop with no resistance!。

  • Voltage source loop with no resistance!（偵測到短路的電壓源/導線迴路！）：電壓源被短路，每個電壓源兩端都要有電阻。
  • Capacitor loop with no resistance!（無電阻的電容迴路！）：電容組成的迴路裡沒有電阻。並聯電容不被允許，要串一顆電阻。電容短路則可以。
  • Singular matrix!（奇異矩陣！）：電路矛盾（兩個不同電壓源接在一起），或某點電壓沒有定義。元件腳還沒接上也會。
  • Convergence failed!（收斂失敗！）：算不出來。按 Reset（重置）。太複雜或只是例題也會偶發。
  • Transmission line delay too large!（傳輸線延遲太大！）／Need to ground transmission line!（傳輸線需要接地！）：傳輸線延遲相對 time step 太大，或傳輸線下方兩條線必須接地。初學可以先忽略傳輸線。

⑥ 它不是什麼

官方說明裡就能加電晶體，也能加運算放大器。運算放大器預設電源極限 ±15 V，畫面不畫出這組電源，Edit 可改。Circuits（電路）選單的範例裡有邏輯。零件不只有電阻和電池。

  • 零件是通用模型，不是某家料號的規格書。沒有購物按鈕，也對不上嘉立創或 DigiKey 的庫。
  • 接錯時它仍可能畫出很有信心的圖。新手要會用上面的錯誤訊息和歐姆定律抽查，不要把動畫當真。
  • 黃點速度不是電流大小的唯一線索，看旁邊的數字。
  • 跟本站 from-zero 的分工：Falstad 看電壓和電流。它不演出機器人在動，也不產出 Gerber。直流馬達在這裡只能先當成一顆電阻看「這條線要多少電流」，不能拿來算力矩或溫升。
