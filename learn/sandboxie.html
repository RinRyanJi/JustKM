📦 Sandboxie:Windows 的沙箱隔離,跑程式不改到系統

老牌的 Windows 沙箱隔離軟體:在一個受控的虛擬環境裡跑或裝程式,不會永久改動你的本機/對應磁碟與登錄檔——測試不信任的程式、隔離上網、分析惡意軟體都很適合。可建幾乎無限個沙箱,各自獨立、彼此隔離、也和主機隔離。2020 年 Sophos 開源後由 David Xanatos 接手社群分支,分 Plus(現代 Qt UI) 與 Classic(舊 MFC UI) 兩版,核心相同、安全性一致。Windows 7+(64 位)。

⓪ 一句話總結

一個「把程式關進盒子裡跑、關掉盒子就當沒發生過」的 Windows 沙箱。你在 Sandboxie 的沙箱裡安裝或執行任何程式,它讀得到你真實的系統,但所有寫入都被攔下來、導進沙箱自己的空間——不會永久改到你的硬碟檔案與 Windows 登錄檔。要測一個來路不明的安裝檔、開一個可疑網站、分析惡意程式、或讓同一個程式開很多份互不干擾,丟進沙箱就對了;刪掉沙箱,裡面的改動一併消失。

它在這份筆記裡的位置:和站內 REA(逆向)、Sherlock(OSINT) 同屬資安工具一類;Sandboxie 是「隔離/防護」這一側的經典。注意:這是 Sophos 於 2020 年開源後的社群分支(sandboxie-plus,David Xanatos 維護),不是舊開發團隊的官方延續。GitHub sandboxie-plus/Sandboxie。

① 核心機制:讀穿透、寫重導(copy-on-write)

Sandboxie 的靈魂就一句話——讀的時候看得到真實系統,寫的時候全被導到沙箱裡。程式以為自己在正常改檔案、改登錄檔,實際上那些變更只落在沙箱的私有空間,主機原封不動。

▲ 這就是為什麼「在沙箱裡裝軟體/中毒/亂改」都不會污染你的系統:寫入從不碰主機。你可以同時開很多個沙箱,彼此之間一樣互相隔離。

② 它能拿來幹嘛

  • 測試不信任的程式:來路不明的安裝檔、綠色軟體、破解檔,丟沙箱跑,看它到底想幹嘛,不怕弄髒系統。
  • 隔離上網 / 無痕:在沙箱裡開瀏覽器,下載的東西、cookie、快取都關在盒子裡,關掉即清。
  • 惡意程式分析:安全研究者在受控環境觀察樣本行為(搭配下方工具生態看它改了哪些檔/登錄)。
  • 程式多開、互不干擾:同一個程式在不同沙箱各開一份(例如多帳號),或讓它們彼此隔離。
  • 保護主機:沙箱不只保護主機不被改,還能反向保護沙箱不被主機窺探(見 ⑥,連截圖都能擋)。

③ Plus vs Classic:核心相同,差在 UI 與新功能

兩版共用同一套核心元件,所以安全性與相容性完全一樣;差別只在使用者介面與新功能的可用性:

Sandboxie PlusSandboxie Classic
UI現代 Qt 介面舊的 MFC 介面(Sandboxie Control)
新功能✅ 支援開源後新增的全部功能⚠️ 介面上沒有;部分可手動改 Sandboxie.ini 或用腳本替代
開發狀態主力開發UI 已不再開發
適合想用最新安全選項的人(推薦)習慣舊介面、需求單純的人

README 明講:想探索最新安全選項的使用者不建議用 Classic。Plus 也保留了一個「Vintage View」模式,能重現 Classic 的外觀給懷舊的人。

⑥ 進階隔離能力(開源後的重點)

  • 安全強化盒(Security enhanced):進一步限制盒內可用的 syscall 與端點,縮小攻擊面——比「只是重導寫入」更硬的隔離。
  • 每盒網路防火牆(WFP):每個沙箱有自己的防火牆規則,配合強制 SOCKS5 代理與 DNS 封鎖/重導,能精準掐住盒內程式的對外連線。
  • Privacy 模式 / 防主機窺探:不只保護主機不被盒內程式改,還反向保護盒——防止主機端(或其他程式)讀取盒內資料,甚至防止對沙箱視窗截圖。
  • 加密沙箱:以 AES 加密盒內資料儲存,靜態資料更安全。
  • 資源與身分:限制記憶體與程序數、用全新 token 機制讓盒更獨立於系統、防止盒內程式以常規方式產生唯一識別碼(抗指紋追蹤)。

⑧ 重點 · 關聯 · 來源

七個帶得走的重點

  1. Windows 沙箱:在盒裡跑/裝程式,讀穿透、寫重導,主機硬碟與登錄檔零改動。
  2. 刪掉沙箱 = 乾淨環境;可開幾乎無限個盒,彼此與主機都隔離。
  3. 用途:測不信任程式、隔離上網、惡意程式分析、程式多開。
  4. Plus(Qt)與 Classic(MFC)核心相同、安全性一致,差在 UI 與新功能;新功能選 Plus。
  5. 架構:核心驅動(SbieDrv)+ 服務(SbieSvc)+ 注入 SbieDll.dll + 受限 token。
  6. 進階:安全強化盒(限 syscall)、每盒 WFP 防火牆、SOCKS5/DNS、加密盒、防截圖。
  7. 身世:Ronen Tzur→Invincea→Sophos→2020 開源→David Xanatos 社群 fork;Plus 自訂授權 / Classic GPL。
