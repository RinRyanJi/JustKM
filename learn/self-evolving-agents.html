⓪ 什麼是自我演化 Agent

自我演化 Agent（Self-Evolving Agents）指的是一種範式轉變：讓 AI agent 系統能自主地持續改進自己，而不是訓練完就定型。改進的途徑分三條——改進模型本身、強化與環境的互動經驗、以及讓模型與環境同時共同演化。

一句話：傳統模型是「訓練 → 凍結 → 部署」；自我演化 agent 是「部署後還會邊做邊變強」——靠推理時自我修正、累積經驗記憶、演化工具與架構，甚至自己造環境來練。

本頁整理自廈門大學 XMUDeepLIT 實驗室的綜述論文《A Systematic Survey of Self-Evolving Agents: From Model-Centric to Environment-Driven Co-Evolution》(2026) 及其 Awesome list，把龐大的論文地圖濃縮成可導覽的中文結構。

① 三大維度總覽

維度演化什麼核心手法
② 模型中心
Model-Centric		模型本身的推理與參數推理時(平行取樣、序列自我修正、結構化推理)＋訓練時(離線合成、線上探索)
③ 環境中心
Environment-Centric		外部知識、經驗、架構靜態知識演化、動態經驗演化、模組架構演化、拓撲演化
④ 模型-環境共同演化
Co-Evolution		兩者同時多代理策略共演、環境訓練(課程/可擴展環境)
怎麼讀這張地圖：由內而外——先看能不能把模型本身變強(②)；不夠就讓環境/經驗幫它變強(③);最強的是兩邊一起長(④)，模型與它所處的環境互相把對方推上去。

② 模型中心演化（Model-Centric）

推理時演化（Inference-Based）— 不改參數，靠「怎麼想」

手法做法代表工作
平行取樣多路答案再彙整/投票Self-Consistency、Large Language Monkeys、LLM-Blender
序列自我修正產出→批判→修正的迭代Self-Refine、Self-Debug、Reflexion、CRITIC
結構化推理把思考展開成樹/圖/搜尋Tree of Thoughts、Think-on-Graph、Language Agent Tree Search、Stream of Search

訓練時演化（Training-Based）🔥 — 真的改參數

類型做法代表工作
離線合成自演化自己造資料再自我訓練Self-Instruct、STaR、Self-Play Fine-Tuning、Beyond Human Data
線上探索自演化 🔥邊探索邊用 RL 自我對弈變強Absolute Zero、R-Zero、SeRL、WebRL、TTCS(測試時課程合成)、Co-evolving Coder & Tester

③ 環境中心演化（Environment-Centric）

模型不動，靠外部的知識、經驗、記憶、工具與架構變強。這是與 agent 工程最相關的一塊。

靜態知識演化 — 檢索與深度研究

  • Agentic RAG：Self-RAG、Search-o1、Search-R1、MindSearch——讓檢索本身變成會推理、會批判的動作。
  • 深度研究(Deep Research)：WebVoyager、DeepResearcher、WebWeaver、Tongyi DeepResearch——多步搜尋+彙整成報告。

動態經驗演化 🔥 — 記憶與經驗累積(最貼近實務)

子類意義代表工作
離線經驗編纂把做過的事整理成可複用經驗SkillWeaver、Agent KB、ARCMEMO、Procedural Memory
線上經驗調適測試時即時調整記憶Dynamic Cheatsheet、Memento、GEPA、Agentic Context Engineering
終身經驗演化 🔥跨任務長期累積ReasoningBank、AgentEvolver、FLEX、Memgen、LatentEvolve
技能增強演化 🔥創建/評估/連結技能AutoSkill、SkillRL、SkillNet、ARISE、SkillsBench

模組架構演化 — 記憶架構與工具

  • 互動協定/記憶架構：MemGPT、MemoryBank、A-Mem、Mem0、Memory-of-Thought、AgentFold——把記憶做成可管理的系統。
  • 工具增強：ReAct、WebGPT、PAL、Voyager、CRAFT、Gödel Agent、ALITA、EvoTest——會用工具、甚至自己造工具。

Agentic 拓撲演化 — 多代理結構自動設計

  • 離線架構搜尋：AFlow、AutoFlow、Agents as Optimizable Graphs、Automated Design of Agentic Systems。
  • 執行時動態調適：EvoAgent、AutoAgents、G-Designer、Adaptive Graph Pruning、REMA。
  • 結構化狀態演化：G-Memory、SEDM、Collaborative Memory(含存取控制)。

④ 模型-環境共同演化（Co-Evolution）🔥

最強、也最難的一類：模型與環境同時演化，互相把對方推上去。

多代理策略共演

多個 agent 在互動中一起變強：Stronger-MAS、Group-Evolving Agents、CORAL、MapORL、MarFT、CoMAS(靠互動獎勵共演)。

環境訓練 🔥 — 讓環境也跟著長

  • 自適應課程演化：GenEnv(難度對齊共演)、RLVE、「別只調 agent，也調環境」。
  • 可擴展環境演化：AgentGym、GEM、Reasoning Gym、AutoEnv、ScaleEnv、Endless Terminals——自動合成/擴展訓練環境。
核心洞見：當任務越做越好、環境卻不變難，agent 就停滯。讓環境隨 agent 能力自動加難(課程)，才能持續逼出成長——這就是共同演化的精神。

⑦ 應用（自我演化落地在哪）

自動科學發現

AI Scientist(自動寫論文)、AlphaProof(IMO 銀牌級數學)、ChemCrow、Coscientist、GNoME(發現 220 萬晶體)、A-Lab(71% 合成成功率)、CRESt。

自主軟體工程

SWE-agent、Claude Code(技能累積、資深級)、Devin、Cursor(人機共演)、Manus、OpenClaw。

開放世界模擬

Voyager(Minecraft，探索-寫程式-儲存技能，15.3× 更快)、GITM、Cradle(GUI 控制)、Generative Agents(社會模擬)、Project Sid(湧現經濟)、SIMA、Genie(可互動世界模型)。
