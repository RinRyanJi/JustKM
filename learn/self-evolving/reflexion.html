🪞 Reflexion：用「語言」當回饋的自我修正 Agent

Reflexion: Language Agents with Verbal Reinforcement Learning · Shinn et al., NeurIPS 2023 · arXiv 2303.11366

言語強化學習 不更新模型權重 Actor · Evaluator · Self-Reflection
📑 目錄 · 重點在「怎麼實現」

⓪ 一句話總結

Reflexion＝把失敗經驗寫成一段「檢討文字」，存進記憶，下一輪重試前先讀它。不動任何模型權重，靠語言回饋（verbal reinforcement）取代梯度更新，讓 language agent 在多次嘗試（trial）之間越做越好。

傳統強化學習要靠大量樣本＋昂貴微調才能把「這次錯了」的訊號寫回模型。Reflexion 把這個回饋改成「一段自然語言的自我反省」，存進 episodic memory（情節記憶），在下一次嘗試時當成 context 餵回 agent——用讀文字取代改參數。

① 想解決什麼問題

Language agent（如 ReAct）在互動式任務中會犯錯，但要它「從錯誤中學」有兩條傳統路，兩條都不好走：

傳統做法痛點
用 RL 微調模型權重需要大量 rollout 樣本、算力昂貴；對數百億參數的 LLM 反覆做 fine-tune 不切實際
只給標量獎勵一個數字（成功/失敗、分數）資訊量太稀薄，agent 不知道「錯在哪、下次該怎麼改」

作者的核心提問是：能不能不改權重，只用「語言」當回饋，就讓 agent 反思、記住、然後變好？語言的好處是資訊密度高——它能表達「我剛剛在第 3 步走錯房間、應該先找鑰匙」這種具體、可行動的檢討，而不只是「失敗了」。

關鍵轉念：把「學習」從更新參數搬到更新記憶。模型是凍結的，變的是它每一輪讀到的 context。

② 核心想法：Actor–Evaluator–Self-Reflection 三元件

Reflexion 把一個會反省的 agent 拆成三個角色，彼此分工：

元件職責怎麼實作
Actor（行動者）依當前 context 產生行動 / 文字，實際去做任務一個 LLM，通常用 ReAct 或 CoT 當底層策略；會讀取記憶中的反思
Evaluator（評估者）對 Actor 這一輪的軌跡打回饋分數／判斷成敗可以是規則（如單元測試通過否）、環境給的標量獎勵、或另一個 LLM 啟發式評分
Self-Reflection（自我反省）把「軌跡＋回饋」轉成一段具體、可行動的語言檢討一個 LLM：輸入是這次失敗的軌跡與訊號，輸出是「下次該怎麼做」的自然語言

三者透過一塊 episodic memory（情節記憶） 串起來：Self-Reflection 產生的文字被存進記憶，Actor 在下一輪開始前把它讀進 context。這就是整個系統的「學習載體」——不是權重，是一段段累積的反省文字。

為什麼要拆三塊：評估「對不對」（Evaluator）與檢討「為什麼錯、怎麼改」（Self-Reflection）是兩件事。把稀薄的回饋訊號先「翻譯」成濃密的語言指引，Actor 才有可操作的改進方向。

③ 怎麼實現：一圈 trial 迴圈

Reflexion 的執行是多次嘗試（trial）的外層迴圈。同一個任務允許重試 N 次，每次重試前都帶著前幾次累積的反省。單一 trial 走這五步：

# Reflexion 的一輪 trial（模型權重全程凍結）
memory = []                      # episodic memory：存歷次語言反思

for t in range(max_trials):
    # 1) 行動：Actor 讀記憶 + 任務，產生一整條軌跡
    trajectory = Actor.rollout(task, memory)     # 底層用 ReAct / CoT

    # 2) 評估：Evaluator 給回饋（標量分數 or 規則 or LLM 判斷）
    feedback = Evaluator.score(trajectory)       # 例：單元測試結果、成功旗標

    if feedback.is_success():
        break                                    # 成功就結束重試

    # 3) 反省：把「軌跡 + 回饋」轉成一段可行動的語言檢討
    reflection = SelfReflection.generate(trajectory, feedback)

    # 4) 存記憶：反思文字進入 episodic memory
    memory.append(reflection)                     # 滑動視窗，只留最近幾條

    # 5) 下一輪：Actor 帶著新反思重試同一個任務

五步逐一拆解

  1. 行動（Act）：Actor 把「任務描述＋記憶裡的歷次反思」一起當 prompt，跑出一條完整軌跡（一連串思考／動作／觀察）。
  2. 評估（Evaluate）：Evaluator 對軌跡給回饋。回饋可以很多形式——程式任務用單元測試是否通過；決策任務用環境的成功／失敗訊號；推理任務可由 LLM 做啟發式判斷。
  3. 反省（Reflect）：若失敗，Self-Reflection LLM 讀「這次軌跡＋為何失敗」，輸出一段具體檢討，例如「我一直嘗試打開沒鎖的抽屜，應該先去書桌找鑰匙」。這段話比單一分數資訊量高得多。
  4. 存記憶（Store）：反思被 append 進 episodic memory。記憶通常是滑動視窗（只保留最近 1～3 條）以免 context 爆掉。
  5. 下一輪帶入（Reuse）：下一次 trial，Actor 的 prompt 前面就多了這些反思。等於「上一次的教訓」直接寫在它眼前，引導它避開同樣的坑。
全程不動權重：整個迴圈裡沒有任何 backprop、沒有 gradient、沒有 fine-tune。「學到的東西」100% 存在記憶文字裡，是一種 in-context 的、可解釋的「學習」。

④ 關鍵細節

Verbal RL 與傳統 RL 的對照

傳統 RLReflexion（Verbal RL）
回饋形式標量獎勵（一個數字）自然語言檢討（＋可用標量／規則當觸發訊號）
學習載體模型權重episodic memory 裡的反思文字
更新方式梯度下降 / policy gradient把反思寫進下一輪的 context
樣本效率需大量 rollout幾次 trial 就能明顯改善
可解釋性低（權重難讀）高（反思是人可讀的文字）

記憶怎麼注入 context

  • 短期記憶（軌跡本身）：當前 trial 內的思考／動作／觀察，是 Actor 的即時工作記憶。
  • 長期記憶（跨 trial 反思）：Self-Reflection 產生的檢討文字，跨越多次嘗試被保留，是 Reflexion 的核心創新。
  • 滑動視窗：為控制 context 長度，episodic memory 只保留最近數條反思（論文設定約 1～3 條，以原論文為準）。
  • 注入位置：反思被拼進 Actor 的 prompt（通常放在任務指示之後、行動之前），讓 agent「先看教訓再動手」。

回饋訊號的彈性

Reflexion 的一大賣點是回饋來源與形式都很彈性：可以是外部（環境獎勵、單元測試結果）或內部模擬（LLM 自我評分）；可以是標量或自由語言。只要能產生「這次好不好」的訊號，就能驅動反省。這讓同一套框架橫跨決策、推理、程式三類任務。

⑤ 效果與限制

三大 benchmark 的增益

任務類型Benchmark結果（Reflexion）
程式生成HumanEval (Python)pass@1 達 91%，當時為 SOTA，優於單獨 GPT-4（約 80%）
序列決策ALFWorld成功率提升約 +22%，達到近乎解全（130/134 任務，以原論文為準）
語言推理HotpotQA準確率提升約 +20%（如 34% → 54% 級別的躍升）
怎麼看這些數字：在完全不重新訓練模型的前提下，只靠幾輪語言反思就能拿到雙位數百分點的增益——這正是 Reflexion 影響力的來源：便宜、通用、可解釋。

限制

  • 需要可得的回饋訊號：沒有可靠的成功／失敗判斷（如無單元測試、無明確環境獎勵），反省就沒有依據。
  • 反思品質受限於底層 LLM：若模型本身無法正確診斷失敗原因，產出的檢討可能誤導後續嘗試。
  • 非全域最優：它是啟發式的自我改進，不保證收斂到最優解，且對「非 Markov」的長程任務，記憶視窗大小會成為瓶頸。
  • 成本轉移：省下微調成本，但改用多次 trial＋較長 context，推理次數與 token 開銷增加。

⑥ 在自我演化地圖上的位置

回到本站的自我演化 Agent 綜述地圖，Reflexion 座落在最內圈的「模型中心演化」：

維度子類手法
② 模型中心 Model-Centric推理時演化（Inference-Based）序列自我修正：產出 → 批判 → 修正的迭代

它與 Self-Refine、Self-Debug、CRITIC 同屬「不改參數、靠怎麼想變強」的序列自我修正路線。差別在於 Reflexion 特別強調把反省外部化成 episodic memory 並跨 trial 重用——這一步也讓它與「環境中心演化」裡的經驗記憶累積思路互相呼應。

一句話定位：Reflexion 是「模型中心 → 推理時 → 序列自我修正」這條路上的奠基工作，把「語言反思＋情節記憶」變成後續大量記憶／經驗演化研究的共同語彙。
