🐠 闲鱼 AI 撿漏監控生態全景:六個開源專案怎麼選

闲鱼(Goofish/Xianyu,阿里的二手交易平台)撿漏最累的不是挑,是「盯」——新品秒被搶、半屏不對版、商家混在個人賣家裡。一整群開源專案在做同一件事:機器自動搜新上架 → 規則粗篩 → AI 照你一句話需求把關 → 命中才通知。這頁把六個代表專案拆成三種形態(全棧 Web / 瀏覽器擴充 / Agent Skill)對照,幫你選。

⓪ 一句話總結

同一個需求、三種做法。這群工具解的都是「替你盯闲鱼新上架、用 LLM 過濾垃圾與商家、對版才通知」。差別只在你願意架多重:要功能全開就上全棧 Web 服務(Usagi / tristanwqy / overspread);只想瀏覽器裝個外掛、連後端都省就用Chrome 擴充(lubei0612);已經在用 AI agent、想把監控接進工作流就用Agent Skill(voltwake)。

最推薦的單一入口:Usagi-org/ai-goofish-monitor —— 社群衍生最多、架構最完整(FastAPI + Playwright + React + SQLite + Docker),站內另有它的單卷深潛。

① 共通架構:四段管線

不管哪一個,骨架都是這四段。真正把它們和「土炮爬蟲」拉開差距的是第三段 AI 把關——用自然語言條件讓模型逐品判斷對不對版。

④ 反爬現實:大家其實都在繞闲鱼風控

有件事這些 README 講得很白:闲鱼有嚴格的反自動化偵測(baxia 風控),直接用程式開頁面會被擋成「非法訪問」。所以這群工具的技術重點,很大一塊其實是「怎麼讓機器看起來像真人」。voltwake 的 README 把這點拆得最清楚:

操作結果為什麼
page.goto(搜尋URL)❌ 被 baxia 攔直接導航會觸發風控
AppleScript 在網址列輸入 URL✅ 正常模擬真人在瀏覽器打字
page.click() + keyboard.type() 搜尋✅ 正常產生 isTrusted=true 事件,與真人點擊無異
headless Chrome❌「非法訪問」無頭瀏覽器被直接偵測
非 headless Chrome✅ 正常有真實視窗才過

讀取資料也走被動讀 DOM(從渲染後頁面抓 a[class*="feeds-item-wrap"] 這類卡片),而不是打內部 API。全棧版則多半靠「真實登入態 + 代理池/Cookie 池輪換 + 自適應延遲 + 失敗退避」來撐長時間運行。

這代表什麼:這整類工具本質上是在和平台的反自動化機制「貓捉老鼠」。風控規則會變,今天能用的手法明天可能失效;跑太兇就會踩到限流/封號。這也是為什麼每個專案都提醒「放慢節奏、用小號」。

⑤ 登入態怎麼來:三種取法

因為闲鱼未登入只看得到約 6 小時前的舊貨,要盯實時新品就必須有登入態。三種做法:

  • Chrome 擴充導出 JSON(Usagi):在已登入頁面用專用擴充把登入態導成 JSON,貼進 Web UI → 存成 state/acc_1.json。多帳號好管理。
  • 掃碼登入生 state 檔(tristanwqy / nobugpy):跑一個登入程式彈出瀏覽器,手機 App 掃碼,自動生成 xianyu_state.json。小白友善。
  • 直接複用瀏覽器登入 / CDP Cookie(lubei 擴充 / voltwake):擴充直接用你網頁版已登入狀態;voltwake 啟一個獨立 Chrome 實例,Cookie 存本機約 7 天。
共通風險:不論哪種,都是拿你的真實帳號登入態餵給機器人。這是帳號被風控/封鎖的主要來源,務必用小號、別高頻。

⑦ 風險界線 · 重點 · 來源

合法與風險界線(務必讀):這類工具目的本身合法(幫你盯二手平台、過濾廣告),但手段踩的是闲鱼 ToS / robots.txt 的灰色地帶:自動化抓取、登入態搬移、代理/Cookie 池輪換,本質是繞平台反自動化;自動搶拍/自動下單(lubei)更可能牽涉交易糾紛與平台處罰。各專案 README 幾乎都寫明「僅供學習與技術研究、遵守用戶協議與 robots.txt、勿高頻、勿用於非法用途」,且 MIT 按現狀提供、不負擔保。把它當個人撿漏輔助:用小號、放慢節奏、別商用大規模抓取、別拿去做自動搶單牟利。

六個帶得走的重點

  1. 整類工具解同一件事:自動搜新品 → 規則粗篩 → AI 把關 → 通知。
  2. 靈魂是 AI 看圖 + 讀描述,照一句話需求逐品判斷對不對版。
  3. 三種形態:全棧 Web / 瀏覽器擴充 / Agent Skill,越右越輕。
  4. 要盯實時新品必須有登入態(未登入只見 ~6 小時前舊貨)。
  5. 技術重點一半在繞風控:非 headless、真人式輸入事件、被動讀 DOM、代理/Cookie 池。
  6. 最完整、最值得起手的是 Usagi;要省事選桌面版 tristanwqy 或擴充 lubei。
