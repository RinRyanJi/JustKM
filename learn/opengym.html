🏋️ openGym:自己託管的健身追蹤 App(資料就是一個資料夾)

大多數健身 App 把你的資料鎖在它的伺服器、逼你訂閱、公司收掉就消失。openGym 反過來:跑在你自己的機器上,資料放在你掌控的一個資料夾裡,隨你 fork。它仍然像一個現代 App——裝到主畫面(PWA)、Passkey 登入、離線可用、手機和筆電之間同步。沒有別人伺服器上的帳號、沒有訂閱、沒有廣告、沒有遙測,一行 docker compose up 就跑起來。AGPL-3.0。

⓪ 一句話總結

一個「你自己擁有」的健身紀錄與訓練規劃系統。它把現代健身 App 該有的功能(5,600+ 帶動畫的動作、漸進規則、PR 偵測、肌肉圖、手機/手錶 App)都做了,但關鍵差別在資料主權:後端是輕量 Node.js,資料直接以結構化 JSON 存在你機器上的一個資料夾——備份那個資料夾,就等於完整帶走你全部的訓練史。AI 完全是可選的:預設安裝不呼叫任何 AI 服務。

它為什麼值得放進這份筆記:openGym 是一個「自託管架構 + 離線優先同步」的漂亮範例——尤其它的欄位級合併同步(見 ③)和「資料即 JSON 檔」的設計很值得學。另外它本身大量用 Claude Code 開發(repo 帶 CLAUDE.md),還提供可選的 AI 教練與 MCP 伺服器,正好扣住這份筆記的主題。官網 opengym.ch(有線上 demo),原作者 DuarteSantos8/openGym。

① 為什麼自託管:資料是你的,不是別人伺服器上的

商業健身 App 的三個老問題:資料在它伺服器、逼訂閱、公司倒了 App 就沒了。openGym 的設計哲學就是逐條反掉:

  • 資料在你掌控的資料夾:全部存在 host 上的 ./data,是人類可讀的 JSON。沒有綁定雲端、沒有專有資料庫。
  • 備份 = 複製一個資料夾:把 ./data 複製走,就備份了一切(見 ⑧ 的檔案清單)。要搬家、要 fork、要離開,都隨時。
  • 無訂閱、無廣告、無遙測:AGPL、沒有付費層、沒有為贊助者保留的功能。預設安裝不呼叫任何 AI 服務。
  • 一行跑起來:docker compose up,開 http://localhost:8080,建 profile 就進去了。動作動畫打包在映像裡,沒有別的要下載。
要從手機用 Passkey:需要 HTTPS + 一個網域(.env 改兩行)。官方自託管指南涵蓋 Cloudflare Tunnel、Caddy、Traefik、nginx,另有 LAN HTTPS、Mac + Tailscale、Kubernetes 的專門指南。登入出問題幾乎都是 RP_ID/ORIGIN 對不上(Passkey 綁定主機名)。

▲ 前端是 React 19 + Vite(React Router、Zustand),建成靜態檔;api 是裸 node:http,只靠三個依賴;web 用 nginx 把前端與 /api 收在同一 origin(Passkey 要求同源)。

訓練邏輯(漸進規則、1RM、如何回讀一場已記錄的訓練)刻意寫成 frontend/src/lib/ 下的純函式,旁邊就是測試——這是「AI 或人寫的程式看起來對、其實錯」的防線。HTTP API 有 OpenAPI 規格。

③ 同步怎麼運作:欄位級合併,不是整碗覆蓋

自託管 + 多裝置最難的就是同步衝突。openGym 的做法乾淨又好懂:每個 profile 的資料是一份文件,帶一個伺服器修訂號(revision)。

← 左右滑動看完整圖 →
▲ 關鍵:衝突不是「後寫的蓋掉先寫的」,而是每個欄位各帶時間戳、逐欄位合併——兩台裝置同時編輯也能保住各自最新的那一筆,刪掉的保持刪掉。

這種「樂觀並發 + 欄位級 CRDT 式合併」是離線優先 App 的教科書做法:裝置先存自己的,撞到別人就把對方文件抓回來合併再存,而不是粗暴地整份覆蓋。

④ 規劃與訓練

規劃(Planning)

  • 5,600+ 動作(v1.4.0 起 5,632 種)附動畫示範,可搜尋、可用身體圖按肌群瀏覽、可依你擁有的器材過濾。
  • 四套起手計畫(Push/Pull/Legs、Upper/Lower、Full Body、5×5),載入即是可編輯的 routine。
  • 不想按星期?用 rotation(A、B、C、A…),下一場就是你還沒做的下一個。
  • 超級組、熱身組、遞減組、rest-pause、計時動作(棒式/懸垂/負重行走)、按時間與速度的有氧、每動作的組間休息、計畫性 deload。自訂動作可放自己的照片/GIF/短片(上傳前在裝置端去除位置資訊)。

訓練(Training)

  • 引導式訓練:今天的課自動開始、重量用上次的預填、組間休息計時、邊做邊偵測 PR。
  • 可選 RIR / RPE 強度欄(顏色標記 + 白話說明)。
  • 槓片數學(槓鈴/EZ 槓/trap bar/史密斯機),按你擁有的槓片算;每間健身房各自記自己的槓片、啞鈴、槓、器材配重,走進哪間就切哪間。
  • 自體重動作知道自己沒負重(可加負重腰帶);單邊動作分邊記;訓練時螢幕保持亮;器材被佔用時一鍵換上備用動作、保留該格的組數次數;一場的總量(volume)即時跑在進度條末端。

⑤ 進度追蹤

  • 漸進規則(每 routine 或每動作):線性、Greyskull LP、經過可見次數區間的雙重漸進、三重漸進(次數→組數→負重)、加時間。每個目標都解釋「為什麼是這個數字」;沒完成的次數永遠不加重,停滯就觸發 deload。
  • 每動作的估計 1RM(各有曲線)、結構平衡比例(Poliquin、Thibaudeau、ATG)、一整年的活動熱力圖。
  • 肌肉圖三種模式:量去了哪、還在恢復中、以及哪裡沒練到。
  • 體重對目標線的圖(含每週速率、可選增/減/維持區間)、進度照片時間軸含前後對比滑桿、把舉重當體重百分比、以及你這輩子總共舉起的重量。
  • 事後可編輯任何已存的訓練、補登紙上做的、或移到正確日期——紀錄會從更正後的歷史重新回讀。

⑥ 像個現代 App:PWA / Passkey / 手機與手錶

  • Passkey 登入(Face ID / Touch ID / 指紋),每個 profile 資料跨裝置同步;可改用密碼登入;新裝置用一次性碼或 QR 配對。Passkey 私鑰永遠不上伺服器,留在手機安全硬體或你的密碼管理器。
  • PWA:裝到桌面/手機主畫面、離線可用。
  • 手機與手錶:iPhone/iPad/Android App(可純離線用、或連你的伺服器同步,用 Capacitor 同一套碼庫建),Apple Watch App(用數位錶冠勾選組、手腕上給 RIR/RPE、全螢幕休息倒數、每組心率),iPhone 小工具 + 鎖定畫面 Live Activity。Apple Health / Health Connect 雙向(訓練出去、體重與每組心率回來)。
  • Modules:在設定裡把整塊功能開關掉(從「只訓練」到「全部」),關掉的部分完全消失但不刪資料。
  • 匯入 FitNotes / Strong / Hevy(CSV 或 API key)與 Apple Health 體重;匯出成一份 JSON 或 CSV 試算表。26 種語言(含 RTL 的阿拉伯語/波斯語,以及繁體中文)。

⑦ 可選的 AI 教練與 MCP(預設關閉)

AI 在 openGym 裡是加分項,不是必需品——預設安裝完全不碰 AI。兩個可選件:

  • AI 教練:幫你起草一週 routine,之後根據你實際記錄的(停滯、強度評分、達成率、體重趨勢)提出一條條、附理由、可逐一接受的修改。跑在你的伺服器或手機上,用你自己的供應商金鑰(Anthropic / OpenAI / Gemini / 任何 OpenAI 相容端點,含 Ollama)。每個改動都要你批准,且 session 到 session 的重量仍由漸進引擎決定,不是 AI。
  • MCP 伺服器:讓 Claude Desktop 這類助手回答你的訓練史問題、或把你口述的一場訓練記下來。本機跑,不在 Docker build 裡。
  • 整合:Apple Health、Health Connect(Garmin/Fitbit/Withings 經此接入),以及完成訓練/破紀錄/量體重時對 Home Assistant、n8n、ntfy 的簽章 webhook。
關於「AI 增強分支」:社群有個 fork alexpcosta/opengym 專門加 AI 教練(Claude Agent SDK 或內建 OpenAI Codex CLI,附 ChatGPT device-code 登入;改動快照化、可還原)。但要注意:原版 upstream 現在本身就內建了 AI 教練與 MCP(見上),所以該 fork 比較像是這條路線較早的版本/快照(其動作庫仍是較舊的 1,324 種)。要新功能,直接用原版 DuarteSantos8/openGym 即可。

七個帶得走的重點

  1. 資料是你的:存成 JSON 在 ./data,備份一個資料夾就帶走全部訓練史。
  2. 無訂閱、無廣告、無遙測;預設安裝不碰 AI;一行 docker compose up。
  3. 架構極簡:React/Vite 前端 + 裸 node:http(只三個依賴) + nginx 同源。
  4. 同步是欄位級合併(revision + 409 衝突 + 逐欄位時間戳),不是整份覆蓋。
  5. 功能完整:5,632 動作、漸進規則、plate math、per-gym、1RM、肌肉圖。
  6. 現代 App 體驗:PWA + Passkey + 離線 + 手機/Apple Watch + Modules。
  7. AI 是可選的:AI 教練(自帶金鑰、每步批准)+ MCP 伺服器;專案本身用 Claude Code 開發。
