🔥 Crucible:給設計師與 AI 代理共用的輕量化 3D 引擎(含 MCP 伺服器)

codepawl/crucible 是一個給網頁用的即時 3D 引擎,主打「設計師與 AI 代理一起塑形同一份場景」。它內建 MCP 伺服器:Claude Code、Cursor、Codex、Gemini CLI 等代理可以用純 JSON 場景資料 + 工具呼叫來建模、打光、匯入 GLB、調鏡頭,再拿回多視角 PNG 預覽自我檢視與修正。雙渲染管線(WebGL2 即時光柵 + 路徑追蹤),核心打包極輕(約 58 KB gzip)。

⓪ 一句話總結

一個「設計師和 AI 代理能在同一份場景配方上協作」的網頁 3D 引擎。場景是純資料:每個 part 就是「幾何 + 一個 4×4 矩陣 + 材質」。AI 代理透過內建的 crucible-mcp 伺服器把這份 JSON 建起來、打光、匯入 GLB、設鏡頭,引擎回傳 PNG 預覽讓代理自己看、自己改;設計師則在同一份配方上掌握構圖、造型、光影、材質。渲染有兩套:Glaze(WebGL2 即時光柵,預覽用)與 Cook(路徑追蹤,出成品)。核心很輕(約 58 KB gzip),能塞進嚴格位元組/記憶體預算的網頁。

定位:它把「AI 代理看不懂視覺、做不了 3D」這道牆,用「場景變純資料 + 多視角 PNG 回授」打穿——和站內 agent-desktop(讀無障礙樹操作桌面)、REA(逆向)是同一個精神:給代理一個結構化、可檢視、可迭代的介面。MIT、npm @codepawlhq/crucible(舊名 67js)、Node 20.19+、ESM。

一般 3D 引擎對 AI 代理很不友善:要寫一堆 API、擺相機、還「看不到」結果。Crucible 的做法是把這條路變成一個閉環:

▲ 關鍵是「代理能看到自己做的結果」:引擎回傳 PNG,代理像人一樣看圖找問題、改 JSON 再渲染——這把「盲寫 3D」變成「可迭代的視覺任務」。

分工很清楚:代理扛技術重活(幾何、修飾器、打光、檢查、匯出),設計師保留創意控制(取景、造型、光影、材質),兩邊操作的是同一份場景配方。

④ 品質分層與效能(對 Blender 基準)

一個 quality 設定把渲染分四層;官方用 6 個場景、960×540、對 Blender Cycles 4096 樣本當參考算 FLIP 誤差(越低越好):

層用途怎麼跑Crucible 實測對照 Blender
draft編輯時快速看Glaze,0.5 render scale,1 樣本每幀約 0.5–1.0 ms(含讀像素)EEVEE 1 樣本:56–59 ms/次
realtime互動使用Glaze 預設每幀約 0.77–0.98 msEEVEE 64 樣本:288–363 ms/次
realtime-high更好的互動幀(規劃中)Glaze on WebGPU + GI 快取 + 升頻尚未可測—
final完成的靜圖Cook native 256 樣本(Vulkan)256 樣本約 0.71–1.32 s(含設定)Cycles OptiX:3.43–8.46 s
怎麼讀這些數字:Glaze 即時層在這些場景上 <約 1ms 一幀(960×540,含讀像素);Cook 出 256 樣本的成品比 Blender Cycles 快數倍。但這是「單一顯卡、理想場景」的量測,EEVEE 的時間含完整背景渲染與場景同步、不是幀率比較——當量級參考,別當保證。

⑤ 輕量化與網頁預算:約 58 KB gzip

它是為「網頁嵌入」設計的,所以體積與執行期預算被當第一等公民:核心打包約 58 KB gzip(據專案說明,比 Three.js 精簡超過一半);匯出的場景在網頁上保持輕量、守住嚴格的位元組與記憶體預算。

  • 每個 addon 是獨立 import:一個頁面只載它用到的功能(地形、草、角色…各自分開),不會把整包拖進來。
  • 記憶體預算:渲染器可設 memoryBudgetMiB;串流 addon 有位元組預算 + LRU 淘汰 + LOD。
  • 影片匯出一次串一幀,整部片不會塞在記憶體裡。

⑦ 安全與上手

MCP 的安全邊界很明確:伺服器不接受任意程式碼、不接受遠端素材 URL。這對「讓代理驅動一個會跑 Chrome 的渲染器」很關鍵——代理只能用定義好的工具操作場景資料,不能塞 code 或拉外部網址。

# 讓代理自己裝(貼給 Claude Code / Codex / Cursor / Gemini)
# 它會裝套件、讀 llms.txt、連上 MCP 伺服器
npx crucible-mcp --backend gpu --memory 192   # gpu=硬體 WebGL2;無顯卡用 --backend cpu

# Claude Code 外掛(一併裝 MCP + 兩個技能)
/plugin marketplace add codepawl/crucible
/plugin install crucible@crucible

# 手動
npm install crucible@npm:@codepawlhq/crucible
  • MCP 需本機裝 Chrome(常駐渲染器);Node 20.19+、ESM;WebGL2/WebGPU 視後端而定。
  • 兩個技能教代理操作:build-crucible-scene(場景與材質)、render-crucible-media(圖片/影片匯出);純文字指南是 llms.txt。
  • 1.0 前每週約一個 minor 版,API 可能變(看 CHANGELOG)。

⑧ 重點 · 關聯 · 來源

七個帶得走的重點

  1. 設計師 + AI 代理共用同一份場景配方的網頁 3D 引擎(舊名 67js)。
  2. 場景就是資料:part = 幾何 + 4×4 矩陣 + 材質 → 代理好生成、設計師好編輯。
  3. AI 原生閉環:代理寫 JSON → 渲染 → 回傳多視角 PNG → 自我檢視修正。
  4. 雙管線:Glaze(WebGL2 即時,~1ms/幀)+ Cook(路徑追蹤,出成品)。
  5. 四個品質層(draft/realtime/realtime-high/final),對 Blender 以 FLIP 量測。
  6. 約 58 KB gzip、addon 用到才載、記憶體預算 + LRU——為網頁嵌入而生。
  7. MCP 不收任意程式碼、不收遠端 URL;npx crucible-mcp 需本機 Chrome。
