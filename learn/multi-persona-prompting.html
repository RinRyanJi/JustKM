🎭 多角色 AI 腦力激盪:從卡帕西 5 角色到完整角色庫與運作法

⓪ 一句話總結

「多角色腦力激盪」是讓 AI 同時扮演數個誘因互相衝突的專家,先各自發言、再由一個整合者裁決。它之所以有效,是因為單一模型回答時會有系統性偏誤——太樂觀、太附和、看不見自己的盲點;讓「務實架構師」「魔鬼代言人」「終端使用者」互相拆台,能把一個模糊概念壓力測試成可執行方案。

卡帕西分享的 5 角色是很好的起點,但確實不夠完整。本頁補三塊:(1) 學理根據——它不是玄學,有 SPP 與多代理辯論兩篇論文撐著,而且只在夠強的模型上才有效;(2) 更完整的角色庫——依決策類型選角的 11+ 個互補角色 + 六頂思考帽;(3) 最常被略過的「抗附和」設計——多角色最大的失敗,是所有角色最後都禮貌地同意一個錯的結論。

① 為什麼多角色能破盲點

單一 AI 回答一個開放問題時,有三個結構性弱點:(a) 過度樂觀——訓練成「有幫助、討喜」,傾向給正面、可行的答案;(b) 單一視角盲點——一次只從一個角度想,漏掉風險、成本、維運;(c) 缺乏內部異議——沒有人逼它為自己找碴。

多角色的解法很直覺:把「一個聲音」拆成幾個誘因不同的聲音,再讓它們辯論。財務角色在意毛利、維運角色在意半夜被叫起來、使用者角色在意學習成本——它們的 KPI 天生衝突,於是自然吵起來,把單一回答藏起來的取捨攤開。最後由「整合者」吸收辯論、排優先級、輸出行動清單。

▲ 各角色「向內」把觀點餵給整合者;整合者不做平均,而是裁決、排序、輸出 P0/P1/P2 行動清單。中央下方的角色可依決策類型從角色庫替換。

② 卡帕西的 5 角色(基礎陣容)

這是很好的預設五人組——涵蓋「發散→收斂→挑錯→校準→整合」的完整弧線。把每個角色的職責邊界講死,是它能運作的關鍵:

角色職責核心提問
🌱 願景開拓者
Visionary		極大化發散與創新若無任何限制,這概念的終極形態是什麼?能創造哪些非對稱價值或顛覆體驗?
🏗️ 務實架構師
Realist / Architect		工程可行性、收斂 MVP拆成具體技術架構、資料流、依賴、步驟;現有工具/算力/成本撐得住嗎?
😈 魔鬼代言人
Devil's Advocate		紅隊思維、風險壓測專挑弱點:失敗點、瓶頸、法規與安全風險、冷啟動、棄用情境。
🙋 終端使用者代表
User Advocate		真實體驗、痛點校準學習成本會不會太高?流程反直覺嗎?是真解痛點,還是只是自嗨?
🧭 執行協調官
Synthesizer		整合衝突、權衡、出路線圖吸收前四者辯論精華,剔除不可行項,排P0/P1/P2,產出 Action Items。
為什麼這五個是好起點:它們的誘因天生衝突——願景要大、架構師要能做、魔鬼要它死、使用者要它好用。有衝突才有真辯論。但這套陣容有兩個缺口:沒有「怎麼衡量成功」的度量角色,也沒有「誰半夜維運它」的營運角色——這正是下面角色庫要補的。

③ 學理根據:這不是玄學

多角色不是「感覺比較全面」而已,背後有兩條被驗證的技術路線,而且它們的差別很重要。

① Solo Performance Prompting(SPP)—— 一個模型,內部多角色

論文《Unleashing the Emergent Cognitive Synergy in LLMs》(Wang et al., 2023;NAACL 2024)。核心叫「認知綜效 cognitive synergy」:單一模型在一次對話裡扮演多個角色互相協作。兩階段運作:

  1. 動態辨識角色:先看任務、從任務本身推出需要哪些專家(不是預先寫死),並固定一個「AI 助理」當協調者。
  2. 腦力激盪 → 多輪自我協作 → 迭代收斂:協調者出草稿 → 各專家補漏挑錯 → 協調者改稿,直到沒人再有異議,才輸出最終答案。
最關鍵的發現:認知綜效是「湧現」的。SPP 的增益只在 GPT-4 出現,在 GPT-3.5 與 Llama-2-13B 上沒有、甚至有害。作者類比人類認知發展——「能有效自我協作」是能力到一定門檻才長出來的。實務結論:多角色請用前沿模型跑;在弱模型上它是雜訊。

② 多代理辯論(Multi-Agent Debate)—— 多個模型,跨實例互批

論文《Improving Factuality and Reasoning through Multiagent Debate》(Du et al., 2023;ICML 2024),作者自稱呼應 Minsky《心智社會》。做法與 SPP 不同:多個獨立模型實例各自先答,再進行數輪辯論——每一輪都把「別人上一輪的答案與推理」給每個實例看,要它挑錯並修正自己的答案,最後取共識。

  • 經典配置:3 個代理 × 2 輪。
  • 成效:比單一 Chain-of-Thought 高約 5–10 個百分點——例如 GSM8K 數學 ~77% → ~85%,並降低事實幻覺。
  • 兩個增益來源:(a) 多個獨立起點(避免錨定)、(b) 跨輪互相糾錯。

兩者對照(一定要分清楚)

SPP(單模型多角色)多代理辯論
結構一個模型、一段脈絡,角色在內部對話多個獨立實例,跨實例互批數輪
多樣性較弱——共用同一顆「大腦」較真——獨立起點、可用異質模型
成本便宜(1×)、連貫貴(N×(輪數+1))、需聚合規則
何時用快速發想、日常決策高風險、硬推理/事實題

④ 何時有效,何時只是「確認劇場」

誠實地說,多角色不是萬靈丹。文獻給的畫面是:

✅ 最有效⚠️ 反而變差 / 浪費錢
知識密集任務(多次檢視能抓出捏造)附和式坍縮:模型被訓練得討喜,辯論常「提早達成共識」——在自信但錯誤的同儕壓力下放棄正確答案(準確率反而隨輪數下降)
多步推理(獨立起點 + 互相糾錯修正算術/邏輯錯)雄辯勝過正確:裁判被流暢的說辭說服,而非被正確性說服
前沿能力模型(SPP 的湧現門檻)同質代理:同模型同提示,辯論只加成本不加多樣性
需要攤開取捨的開放決策確認劇場:看似對抗的角色,其實都在合理化一個預設好的結論
核心心法:價值來自「真正的多樣性 + 抵抗提早同意」,而不是聲音的數量。這也是本頁最想補的一塊——多數科普只講「找幾個角色來吵」,卻略過「怎麼防止他們最後禮貌地同意一個錯結論」(見 ⑧ 抗附和設計)。

⑤ 擴充角色庫:依決策類型選角(11+)

下面每個角色都有不同的目標函數——這是它們「非冗餘」的關鍵。不要全部叫來;挑對這個決策而言誘因衝突最大的 3–5 個。

角色目標函數(它為何非冗餘)核心提問
🔬 第一性原理者把問題拆到物理/經濟/邏輯,從公理重建忽略慣例與類比——什麼是必然成立的?從地基推,別從「大家都這樣做」推
🧠 領域專家(SME)提供該領域的專業知識、術語、地雷作為 20 年老手,內行知道、外行漏掉的是什麼?哪裡違反了業界標準做法?
⚖️ 倫理審查保護「不在場的人」誰可能受害?二階/分配效應是什麼?我們把成本外部化給了誰?
📊 數據度量分析師把方案變成可證偽的指標怎麼知道它成功?定義指標、基線、目標、反指標(什麼會變好但真目標變壞)、要埋什麼數據
✂️ 簡化者(奧坎剃刀)對抗複雜,找最小可行能刪什麼?哪 20% 拿到 80%?有沒有無聊的現成方案?為「做更少」辯護
📜 前例偵查(歷史學家)查這事有沒有人做過、怎麼死的公司內外有沒有前例?上一次嘗試被什麼殺死?類似點子的墳場在說什麼?
🛡️ 鋼鐵人(Steelman)建構對立面最強的版本強論證,別稻草人。用最聰明的支持者口吻,建立「反對本案/支持被否決方案」的最佳論述
💰 客戶 / 上市(GTM)擁有「需求與收入」作為客戶:這是止痛藥還是維他命?作為業務:一句話賣點?什麼異議會殺單?對手是誰?
📕 法務 / 合規法規、合約、IP、隱私、責任曝險碰到哪條法規/授權/ToS(GDPR、授權條款、產業規範)?最壞責任是什麼?最省力的合規路徑?
🌙 營運 / SRE(半夜維運者)可靠度、on-call 負擔、長期維護它在生產環境怎麼壞?半夜三點被叫起來看什麼?回滾、監控、雜務、五年養它的成本?
🧮 財務 / 單位經濟單位與規模化下的錢算不算得過每用戶/每筆成本、毛利、回本期?放大 100 倍還賺錢嗎?藏起來的 run-rate(算力/客服/基建)?
📣 說書人 / 溝通者
溝通重時加		讓不在場的人也聽得懂、記得住濃縮成一個訊息、一條敘事弧、一個比喻。講不簡單,就還沒想清楚。
選角範例(挑衝突最大的):
  • 產品賭注:客戶/GTM + 營運/SRE + 財務 + 魔鬼代言人
  • 倫理敏感的發布:倫理審查 + 法務 + 數據度量 + 鋼鐵人
  • 技術設計:第一性原理 + 務實架構師 + 營運/SRE + 簡化者

⑥ 兩個經典互補框架

de Bono 六頂思考帽

de Bono(1985)的《六頂思考帽》強迫「一次只用一種思考模式」,得到平行思考而非爭吵。它剛好補上卡帕西陣容缺的「紅帽」——直覺/情緒通道,對讀「使用者與利害關係人的感受」特別有用。

▲ 五頂「內容帽」+ 一頂「流程帽」。藍帽 ≈ 整合者、黑帽 ≈ 魔鬼代言人、黃/綠 ≈ 願景、白 ≈ 數據度量;紅帽是卡帕西陣容原本沒有的情緒通道。

紅隊 / 藍隊,與「對抗強度光譜」

紅藍隊源於軍事與資安:藍隊在既定範圍內建構並防守;紅隊是專職對手,唯一目標就是攻破它,手段不設限。這個概念其實比電腦更古老——來自天主教會的 advocatus diaboli(魔鬼代言人),專門唱反調反對封聖候選人。

▲ 對抗不是只有一種強度。要真正有用,紅隊必須攻擊方案「最強的誠實版本」,並替被否決的替代方案 steelman;攻擊稻草人版本毫無價值。

⑦ 四種運作模式:怎麼實際跑

▲ 四種拓撲的成本/多樣性/適用場景。注意:「多樣性顧問議會」的甜蜜點是 3–5 角色,別和「集成投票(對同一題投票,可到 10–40)」搞混——那是另一種技術。

角色數量:3–5 是甜蜜點

  • 低於 3 個,角度多樣性不足;超過 5–6 個進入邊際遞減——協調開銷、觀點重疊,整合者被淹沒。
  • 擴展文獻一致:效能不隨代理數線性成長——先升、後平、再降;辯論的 token 成本約隨代理數平方成長。
  • 多樣性 > 數量。異質代理(不同模型/提示/誘因)比「同一種的更多份」更值錢。

讓角色「真的不同」而非換皮

  • 不同目標函數:營運看 uptime、財務看毛利、GTM 看營收、倫理看避免傷害——KPI 衝突才會真的吵。
  • 不同資訊先驗與評分標準:告訴每個角色「你該注意什麼」「對你而言好答案是什麼」。
  • 強制異議:「你必須找到至少一個與其他角色實質不同意之處;全部同意就是失職。」

⑧ 反模式與「抗附和」設計(最常被略過的一塊)

多角色最大的失敗,是所有角色最後都禮貌地同意一個錯結論。針對每種失敗模式,都有對應的設計:

失敗模式症狀設計對策
附和 / 提早共識被自信但錯的同儕帶跑,放棄正確答案要求每個角色登記一項異議;辯論前先保留「第一輪原始答案」;用多數決取代強迫共識;整合者權衡論證、不數人頭
聲音坍縮成一種所有角色講起來都一樣不同誘因 + 不同評分標準;檢查每個輸出是否含有別人沒有的東西
確認劇場對抗只是表演,都在合理化預設結論替被否決的選項 steelman;給紅隊真實「攻破任務」;寫方案的人和批評的角色分開
過度樂觀偏誤議會整體偏正面加重黑帽/營運/財務;要求一段「什麼會讓它失敗」;做事前驗屍(pre-mortem):「一年後它失敗了,為什麼?」
雄辯勝過正確流暢的錯誤論證獲勝要求角色引用證據;整合者以可驗證性而非自信度評判
成本與延遲辯論是 N×(輪數+1) 次呼叫輪數封頂(2 輪通常夠);便宜情境用單訊息 SPP;只把完整辯論留給高風險決策
弱模型使用綜效根本沒湧現(SPP 發現)多角色只在前沿模型上跑
一句話記住抗附和:強迫每個角色「先獨立、後互看」,並明確允許它說「我不因為要合群而改答案」。禮貌地讓步,是被禁止的。

⑨ 可直接複製的 Prompt 範本

範本 (a):單訊息模擬議會(最便宜,SPP 式)

你是一個專家顧問議會,評估以下事項:<決策 / 方案 / 問題>。

召集恰好 4 位顧問,每位有互相衝突的誘因。從下列中挑對這個問題
最相關的 4 位:第一性原理者、領域專家、魔鬼代言人/紅隊、鋼鐵人、
數據度量分析師、簡化者、倫理審查、營運/SRE、財務/單位經濟、
客戶/GTM、前例偵查、法務/合規。

每位顧問用自己的口吻給:
- 立場:整體判斷(2–3 句)。
- 關鍵點:2–4 個「只有我(基於我的誘因)才會提」的點。
- 最強異議:最讓我擔心的那一件事。

規則:
- 每位顧問必須在某個實質點上與至少一位不同意。全體一致 = 失敗。
- 不得重複別人的點;快重複時,換一個角度。
- 引用具體事實/假設;猜測要標為猜測。

然後扮演整合者(藍帽)。不要平均。產出:
1. 同意 / 不同意 / 未解的張力。
2. 優先級:P0(阻斷)、P1(重要)、P2(nice-to-have)。
3. 行動清單,每項附「完成長什麼樣」。
4. 你的建議(一句話)+ 它最大的單一風險。

範本 (b):多輪結構化辯論(硬題/高風險)

問題:<問題>

進行 3 角色 × 2 輪辯論。角色:<角色 A>、<角色 B>、<角色 C>
——為誘因衝突而選。

第一輪 — 獨立(不准偷看):
每個角色完整、獨立作答,展示推理並標信心(低/中/高)。此輪不得引用他人。

第二輪 — 互批與修正:
把另外兩人第一輪的答案給每個角色。每個角色必須:
- 指出每個他人答案中最強的一點(steelman)。
- 指出每個他人答案中最大的缺陷。
- 只有在被證據(非自信/語氣)真正說服時,才修改自己的答案。
  若不同意,明確寫「我不改我的答案,因為……」。為合群而讓步 = 禁止。

最終:
報告哪裡收斂、哪裡仍分歧。若分歧,呈現雙方答案與各自證據,
不要強迫假共識。給多數答案並註明異議。

範本 (c):整合者步驟(接在任何議會/辯論輸出之後)

你是整合者(藍帽)。以下是顧問/辯論輸出:
<貼上輸出>

你的工作是裁決,不是平均。依序產出:

1. 帳本:每個不同的點一行,標註提出的顧問。一個都別漏。
   標出兩位顧問互相矛盾的點。

2. 張力:真正影響決策的 2–3 個分歧,以及各自賭在什麼上
   (什麼條件成立時哪一方勝)。

3. 優先級:
   - P0 — 進行前必須解決(阻斷、致命傷)。
   - P1 — 重要,盡快處理。
   - P2 — 監控 / nice-to-have。

4. 行動清單:每項寫成「[負責角色] 做 X;當 Y 可觀察/可量測時算完成」。

5. 決策:一句話建議 + 最可能讓它出錯的單一風險 +
   能最便宜降低該風險的一個測試。

以證據與可驗證性加權,不以「幾個顧問說了」或「多自信」加權。
用法提示:日常決策直接用 (a);高風險/會花大錢的決策用 (b) 跑一輪,再把結果丟給 (c) 收斂。三份範本都刻意內建了抗附和句(強制異議、禁止為合群讓步、以證據非自信加權)——這是它們和坊間版本最大的差異。
