🔎 Sherlock:用一個使用者名稱跨 400+ 網站反查帳號

開源情報(OSINT)與資安調查裡最知名的命令列工具之一:給它一個使用者名稱(username),它自動到 400+ 個社群與開發者網站(GitHub、Reddit、X、Instagram、Steam、論壇…)去查這個帳號是否存在,把命中的清單吐給你。Python、MIT,一行 pipx install sherlock-project 就能跑。

⓪ 一句話總結

一個「一名在手、全網反查」的 username 查找器。它的前提很單純:同一個人常在很多平台用同一個使用者名稱。Sherlock 拿你給的 username,平行地去 400+ 個網站各自的「個人頁 URL」探一探,判斷帳號存不存在,把「找到的」整理成清單(可存檔)。它是 OSINT、紅隊偵察、調查記者、找回自己散落帳號的常用起手工具。作者 Siddharth Dushantha,MIT。

它在這份筆記裡的位置:和站內 REA(逆向工程)、CrossDesk 同屬「資安/調查工具」一類;Sherlock 是其中最經典的 OSINT 入門工具。版本 0.16.0。

① 怎麼運作:對每個網站「扇出」查存在性

核心機制不神祕:Sherlock 內建一份各網站的帳號 URL 樣板與「存在判定規則」(存在 data.json 裡)。給一個 username,它就把 username 套進每個網站的樣板、發請求,再依回應(HTTP 狀態、頁面內容、是否導向錯誤頁等)判斷「這個帳號在這個站存不存在」。

▲ 因為是「套樣板 + 判存在」,所以快、也因此會有偽陽性/偽陰性(網站改版、反爬、限流都會影響判定)——命中不等於「一定是同一個人」,見 ⑤。

② 用法與變體

sherlock user123                 # 查一個
sherlock user1 user2 user3       # 查多個(各自存成 user1.txt…)
sherlock "user{?}name"           # {?} 試相近變體(把 ? 換成 _ - .)
sherlock --site GitHub --site Reddit user123   # 只查指定站
sherlock --print-found user123   # 只印找到的;--print-all 連沒找到也印
sherlock --browse user123        # 在預設瀏覽器開啟所有命中結果

其他常用旗標:--timeout(預設 60 秒)、--local/-l(強制用本地 data.json)、--json(從本地或線上 JSON 載入站點清單,也接受 upstream PR 編號)、--nsfw(納入 NSFW 站)、--no-color。

③ 匯出與匿名查詢

  • 匯出:--csv、--xlsx(Excel)、--txt;單一 username 用 -o FILE,多個用 -fo FOLDER 指定輸出資料夾。
  • 匿名:--proxy socks5://127.0.0.1:1080 走代理(搭 Tor 的 SOCKS 埠即可透過 Tor 查);--dump-response 把 HTTP 回應印出來方便除錯誤判。
  • 除錯誤判:--verbose 看指標;--ignore-exclusions 忽略 upstream 的排除規則(會多出偽陽性)。

方式指令 / 說明

⑤ 定位 · 倫理與界線

Sherlock 是合法且主流的工具:常見於授權的滲透測試偵察、CTF、資安研究、調查報導,以及「盤點自己散落在各平台的帳號、好清理數位足跡」。但它本質上是把一個人的網路身分跨平台串起來,所以用途的邊界要清楚:

兩條界線:(1) 別拿來騷擾、起底(doxxing)或跟蹤特定個人——在很多地區這可能違法,也違反平台條款。只在你有正當理由(查自己、授權的調查、公開研究)時使用。(2) 命中 ≠ 同一個人:username 可能撞名、可能是別人註冊、網站改版/反爬會造成偽陽性與偽陰性。把結果當「待查線索」,不是「結論」;重要判斷要人工覆核(--dump-response 幫你看證據)。

這和站內 REA 那頁談逆向的合法界線是同一個精神:工具中立,責任在使用者。

⑥ 重點 · 關聯 · 來源

六個帶得走的重點

  1. 給一個 username,跨 400+ 網站平行查帳號是否存在。
  2. 機制:內建各站 URL 樣板 + 存在判定(data.json),套名發請求判回應。
  3. 用法簡單:sherlock user1 user2;{?} 試變體;--site 限站。
  4. 匯出 CSV/JSON/XLSX/TXT;--proxy 搭 Tor 匿名查。
  5. 一鍵裝:pipx / uv / docker / dnf(注意 ParrotOS、Ubuntu 24.04 第三方包壞掉)。
  6. 命中不等於同一個人;別用於起底/騷擾——工具中立,責任在人。MIT。
