🎮 OhMyGame:用 AI 做遊戲的開源工作室

WhiteTowerAI 開源的 AI 遊戲工作室(桌面 app)。你描述一款遊戲,內建 Agent 就幫你起草設計文件、生美術、寫程式、在即時預覽裡跑起來、還親自「試玩」檢查能不能玩、壞了自動試修,最後發佈成一條誰都能開的連結。設計文件、程式碼、AI 生成的 2D 圖/影片/3D/動畫/音效配樂全在同一塊畫布,不用在五個 app 間切換。Apache-2.0,Beta。

⓪ 一句話總結

一個「描述一款遊戲,Agent 幫你做出來還幫你玩過一遍」的開源桌面工作室。它把做遊戲會用到的所有東西——設計文件(GDD)、程式碼、AI 生成的圖/影片/3D/動畫/語音/音效/配樂——收在同一塊畫布;內建的 Agent 走完整條流水線(設計→美術→寫碼→即時預覽→親自試玩→自動修 bug→發佈)。最特別的是它對 Agent 的三種開放姿態:自帶 Agent、把你裝好的 Claude Code/Codex/OpenCode 當引擎、以及反過來當 MCP 伺服器讓外部 Agent 呼叫它的畫布與素材生成能力。

它屬於哪一類:和站內 Crucible(AI 原生 3D 引擎 + MCP) 是近親——都在把「AI 代理」接進創作流程,且都走 MCP。差別:Crucible 是渲染引擎/庫,OhMyGame 是完整的桌面工作室 + 多引擎編排。官網 ohmygame.ai,支援 macOS(Apple silicon)與 Windows x64,Intel Mac/Linux 在 roadmap。

① 一塊畫布,不用在五個 app 間切換

平常做一款小遊戲:設計文件在 Notion、程式在 VS Code、圖在 Midjourney/Photoshop、音效在另一個工具、3D 在 Blender……來回切換、檔案四散。OhMyGame 的第一個主張就是把這些收進同一塊畫布(canvas),緊挨著程式碼:

  • 設計文件(GDD):Agent 起草、可編輯,和資產放一起。
  • 資產畫布(Asset Canvas):用 AI 生成並整理 2D 圖、影片、3D 模型、動畫、語音、音效、配樂,生成後即可用進遊戲。
  • 程式碼 + 即時預覽:左邊和 Agent 對話,右邊就是它做出來正在跑的遊戲。
  • 素材庫(Library):生成過的資產集中管理、可跨專案複用。
為什麼「同一塊畫布」重要:遊戲開發天然是多媒體 + 程式交織的。把 GDD、美術、音訊、程式放在同一個 Agent 看得到、也動得了的空間裡,Agent 才能真的「邊設計邊實作」,而不是只幫你寫一段孤立的程式。

② 核心迴圈:一個會「自己試玩」的 Agent

多數 AI 編碼工具幫你寫完程式就結束了;OhMyGame 的 Agent 多走兩步——把遊戲跑起來、親自玩、發現壞了就試著修。這是它和一般 coding agent 最大的差別:

← 左右滑動看完整圖 →
▲ 關鍵在「親自試玩」:由 playtest driver 驅動遊戲、game recorder 錄下畫面,Agent 看結果判斷能不能玩、壞了就回頭改——把「寫完就交」變成「玩過才算」。

③ 本機優先的架構:幾乎一切都跑在你機器上

OhMyGame 是 Electron 桌面 app,但內部拆得很乾淨:React 渲染層(UI)↔ 本機 daemon(大腦)↔ OhMyGame Cloud(只負責發佈)。除了「發佈」,其餘全在本機跑。

← 左右滑動看完整圖 →
▲ daemon 是真正的大腦(擁有 agent、試玩、畫布、外掛、MCP、預覽伺服器);Electron 只管桌面與遊戲視窗;Cloud 只在發佈時登場。技術底:Bun 1.4.2+、Node 22.19+。

④ Agent 的三種姿態:自帶 / 當引擎 / 當 MCP 伺服器

這是 OhMyGame 最有意思的設計:它對「誰來當那個 Agent」保持三種開放。

← 左右滑動看完整圖 →
▲ ③ 的巧思:已經在 coding agent 裡工作、也付了模型錢的人,缺的正是 OhMyGame 獨有的媒體供應商、Asset Canvas 與試玩視窗——就把這些當 MCP 工具開放出去。

姿態 ② 與 ③ 方向相反:② 是「OhMyGame 啟動一個 CLI、把 OhMyGame 的工具交給它跑一場對話」;③ 是「外部 agent 透過 ohmygame-studio 這個版本化的 MCP 伺服器,反過來呼叫 OhMyGame」。③ 的工具是一份固定、策展過的公開清單,另有一份 Skill 教用法。

⑤ BYOK 與媒體生成:自帶金鑰、不按次收費

OhMyGame 出貨時不含模型:首次啟動時連一個供應商或你已在用的 coding agent。然後:

  • 自帶金鑰(BYOK)、40+ 供應商:填自己的 API Key,不按次收費(no per-run credits)。專案與金鑰留本機,prompt 直接送你選的供應商。
  • 媒體生成全包:圖片、影片、3D 模型、動畫,以及音訊(語音 TTS、音效、配樂)。音訊供應商看得到 ElevenLabs、Volcengine/Doubao(火山引擎/豆包)等;3D 有專門的 provider 流程;圖片/sprite 還有 pixel-art 修正工具。
  • 只有「發佈」需要帳號;其餘不必登入。
BYOK 的意義:很多 AI 創作工具用「點數/積分」綁住你,生成越多越貴。OhMyGame 走「你自己的 key、原價直連供應商」——對重度生成(一款遊戲要幾百張圖/音效)省很多,也更透明。

⑥ 外掛生態:教 Agent 用上專業引擎

Web 遊戲在瀏覽器裡跑很直接,但 Godot/Unity/Unreal/Blender 這些專業引擎與工具怎麼接?答案是外掛(plugin)。OhMyGame 的外掛不只是 UI 面板——它能教 Agent 新技能、給 Agent 新工具、替 app 加面板與專案類型。

預裝外掛涵蓋:

類別預裝外掛
遊戲引擎Godot、Unity、Unreal Engine
美術 / 資產Blender(3D)、Aseprite(像素圖)、Tiled(地圖)
Web / 內建Phaser、Three.js、React Three Fiber(網頁遊戲最佳起點)
平台發佈微信(WeChat)、抖音(Douyin)小遊戲

外掛系統底層很完整:plugin-mcp-host(外掛可帶 MCP 伺服器)、tool-hooks / plugin-hooks(攔截/擴充工具呼叫)、plugin-sessions(持久連線)、Plugin Builder 與 CLI(packages/plugin-cli、create-ohmygame-plugin、plugin-examples)讓你自己寫外掛。你也能自製外掛掛上自己的引擎或工作流。

⑦ 發佈即一條連結 + 多人同樂

做完按發佈,就得到一條誰都能在瀏覽器打開玩的連結,還會出現在官方 Community。發佈的是靜態建置,部署在 Cloud 上且不可變(immutable)。

  • 多人連線:Web 遊戲可做成多人(桌遊、卡牌到即時競技場),和朋友線上玩,你不用自己架伺服器——房間(rooms)由平台管。
  • 玩家系統隨附:玩家登入、存檔、排行榜一併附上(雲端存檔走 postgres,game-sdk 提供 cloud/account 協定)。
  • 可做的類型:Web 遊戲(Phaser/Three.js/R3F,最佳起點)、互動故事(視覺小說/互動電影/劇情遊戲,用 playable nodes 圖)、一般遊戲(任何引擎/技術棧)。

⑧ 隱私 · 上手 · 重點 · 來源

隱私與上手

  • 隱私:專案與 API key 留在你機器上,prompt 直接送你選的供應商,只有發佈才需要帳號。從原始碼建置不送任何遙測;release 版送使用資料與當機報告,可在「設定 → 關於」關掉。
  • 下載:macOS(Apple silicon)與 Windows x64;Windows 版尚未簽章,首次安裝 SmartScreen 可能會警告。
  • 從原始碼:需 Bun 1.4.2+ 與 Node 22.19+,bun install --frozen-lockfile → bun run dev(web + daemon)或 bun run dev:desktop(Electron)。從 dev 分支開 PR,main 放發行。

七個帶得走的重點

  1. 描述一款遊戲,Agent 幫你設計→美術→寫碼→親自試玩→自動修→發佈。
  2. GDD、程式、圖/影/3D/動畫/音訊全在同一塊畫布。
  3. 最特別的是 Agent 會把遊戲跑起來自己玩(playtest + 錄影)再判斷。
  4. 本機優先架構:渲染層 ↔ 本地 daemon ↔ Cloud(只發佈)。
  5. Agent 三姿態:自帶 Pi / 把 Claude Code·Codex·OpenCode 當引擎 / 當 MCP 伺服器。
  6. BYOK、40+ 供應商、不按次收費;媒體(圖/影/3D/語音/音效/配樂)全包。
  7. 外掛教 Agent 用 Godot/Unity/Unreal/Blender/Aseprite/Tiled 與微信抖音小遊戲;發佈即一條連結、附多人/存檔/排行。
