🛞 從零組一台桌面「輪腿」自平衡機器人(NavBot-EN01)

Frank Fu 的新手向實作記錄:完全沒有硬體經驗,也能用預製 3D 列印件 + 開源資源組出一台會自平衡的輪腿機器人。腦是 ESP32、腿是兩顆 STS3032 數位伺服、輪是無刷馬達。本頁把它整理成一份可讀的「組裝→校正→韌體→測試」指南,並補上「它到底為什麼站得住」的控制原理——順便和前一篇用強化學習走路的 Microduck 對照。

⓪ 一句話總結

一台桌面大小、會自己站直的「輪腿」機器人,用現成套件就能組起來。它把「兩輪自平衡車(倒立擺)」和「可升降的腿」結合:無刷馬達的兩顆輪子負責平衡與移動,STS3032 伺服構成的兩條腿負責姿態/高度。ESP32 讀 IMU、高速閉環修正,開機抬起約 2 秒內自平衡,手機連 WiFi 就能遙控。

定位:這是 NavBot-EN01 套件(fuwei007/Navbot-EN01,navbot.com)的組裝教學,用預製零件(碳纖底板、尼龍腿件、預校正編碼器馬達),適合「想直接玩機器人、先不碰 CAD/從零設計」的開發者。本頁為繁中整理 + 控制原理補充;照片/影片見原文,規格以倉庫為準。

① 什麼是輪腿機器人 · 為何適合新手

輪腿(wheel-legged)是混合體:輪子控制簡單、移動穩,好上手;腿帶你進入步態規劃與平衡演算法(更進階但有收穫)。現實應用如外送機器人、探勘、甚至火星車都用這種設計。相較全雙足,輪腿可以用 3D 列印件 + ESP32 + 數位伺服便宜地做出來。

② 大腦與自平衡原理:ESP32 + IMU 回授

腦是 ESP32:內建 WiFi/藍牙(可手機遙控、IoT),雙核心能同時做感測融合(IMU)與馬達控制,PWM 精準驅動伺服/馬達。它為什麼站得住?——因為它是個倒立擺:重心在輪軸之上,本質不穩,要靠「不斷量傾角、不斷把輪子開到重心下方」來動態維持直立(就像你用手掌頂著一根掃把)。

④ 組裝流程(六步,附關鍵尺寸)

← 左右滑動看完整圖 →
▲ 六步概覽(JustKM 重繪)。多數是鎖螺絲,但三個精度點要留意:輪軸平面對齊、編碼器磁鐵間隙、腿件擴孔。
  1. 底板與配重:碳纖底板 + CNC 配重塊,M3×8 螺絲。
  2. 伺服安裝:短銅柱接伺服模組,STS3032 裝上 CNC 模組、輸出軸朝外,M2.5×10 固定。
  3. 主板安裝:前用長銅柱、後用短銅柱裝 ESP32;螺帽嵌進 3D 列印腿連接件;碳纖側板 M3×6。
  4. 輪轂安裝:3D 列印輪轂+胎裝到無刷馬達,M4×8 無頭螺絲鎖馬達軸;軸平面對齊 ±0.2mm 防打滑。
  5. 編碼器板:磁鐵裝到白色連接柱、裝到馬達綠色位置(可上膠);尼龍燒結腿件擴孔後裝編碼器板。
  6. 腿-馬達連接:金屬柱裝進腿件、套上軸承;螺帽入槽;伺服臂裝進腿件並接到指定位置;長擋泥板朝後;腿接到無刷馬達。

  2. 手機連 WiFi navbot_en01-XXXXXX(密碼 12345678)。
  3. 瀏覽器輸入 192.168.1.11 進控制介面 → 按 Robot Go 並手動抬起,約 2 秒內自平衡。

⑦ 和 Microduck 的 RL 路線比:兩種「讓它站著動」的哲學

站內前一篇 Microduck 是用強化學習在模擬裡學會走路、再 sim2real 到真機;這台 NavBot 走的是經典回授控制(倒立擺 + 手調參數)。兩條路各有適用:

面向NavBot-EN01(經典平衡控制)Microduck(強化學習)
怎麼學會動人寫/調回授控制律(倒立擺)模擬裡 PPO 訓練策略 → ONNX
移動方式兩輪自平衡 + 可升降腿雙足步行 / 換策略滾動
門檻低,新手套件、Arduino高,要 RL/MuJoCo/sim2real
可解釋性高(每個增益看得懂)低(策略是黑箱網路)
適合入門、教學、平地移動複雜步態、崎嶇地形、擬真動作
一句話:輪子讓「平衡」這件難事變簡單(倒立擺是教科書題),所以新手能很快看到成果;真正的雙足走路因為自由度高、動態複雜,才需要 RL 這種資料驅動的方法。先玩輪腿建立直覺,再上 RL,是很合理的學習路徑。

⑧ 重點 · 關聯 · 來源

七個帶得走的重點

  1. 輪腿 = 輪(好平衡、好移動)+ 腿(進階步態/高度);新手友善、便宜。
  2. 本質是能升降的兩輪自平衡車(倒立擺):平衡交給輪、姿態交給腿。
  3. 腦是 ESP32:WiFi/藍牙遙控、雙核做 IMU 融合 + 馬達控制、PWM。
  4. 自平衡 = 高速閉環:量傾角 → 修正 → 把輪子開到重心下,抬起約 2 秒穩住。
  5. 組裝三個精度點:輪軸平面對齊 ±0.2mm、編碼器磁鐵間隙 0.8–1.2mm、尼龍腿件擴孔。
  6. 軟體三步:伺服零位校正(FD 工具、右腿 ID=2)→ 韌體(No OTA 大分區)→ 上電 WiFi 控制。
  7. 和 Microduck 對照:這是經典回授控制(可解釋、低門檻),RL 則適合複雜雙足。
