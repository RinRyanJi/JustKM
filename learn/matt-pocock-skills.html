總覽 / 目錄頁 開發流程 寫作系統 完整 Skill 地圖

📖 這是什麼

Matt Pocock（TypeScript 社群知名教育者、Total TypeScript 作者）把過去一年幾乎全程依賴 AI 開發所摸索出的系統化工作流，打包成一套開源 Agent Skills（給 Claude Code 等 AI 工具用的技能包），放在 github.com/mattpocock/skills。

它的核心目標只有一個：把充滿隨機性的 AI 黑盒子，馴服成精準、可靠、可控的生產力工具。總綱是一句話——

“Always take small, deliberate steps. The rate of feedback is your speed limit.”
永遠踏出小而審慎的一步；你能拿到回饋的速度，就是你能前進的速度上限。

本頁是 JustKM 為這套 repo 做的總覽目錄：下面兩張大卡直接進入兩篇深入拆解，再往下是整個 repo 的 Skill 地圖。

🗺️ 整個 repo 的全景圖

程式開發主線（🏭 已拆解） 需求模糊 ─► grill-with-docs ─► to-spec / to-tickets ─► implement (TDD) ─► code-review ─► commit 寫作系統（✍️ 已拆解） 想法 ─► writing-fragments（探索）─► 碎片堆 ─► writing-shape / writing-beats（開採）─► 文章 共用的底層引擎 grilling（一次一題的訪談）· domain-modeling（磨詞彙 / CONTEXT.md）· handoff（長對話交接）

兩條主線看似不同，其實建立在同一個信念上：先把「探索/釐清」做透，再進入「開採/執行」，全程小步 + 人類掌舵，AI 不越權替你拍板。

🏭 工程（engineering／17）

Skill一句話
grill-with-docs 🔵 ★不留情追問磨利設計，同時長出 CONTEXT.md 詞彙表 + ADR
to-spec 🔵 ★把已討論內容綜合成規格並發到 issue tracker（不再訪談）
to-tickets 🔵 ★拆成 tracer-bullet 垂直切票、宣告 blocking 相依
implement 🔵 ★依規格/票開發，接縫上 TDD、以 code-review 收尾
tdd 🟣 ★紅→綠循環，產出「讀起來像規格、撐得過重構」的測試
code-review 🟣 ★標準 × 規格雙軸、平行子代理審查
diagnosing-bugs 🟣 ★除錯鐵律：先建可重現回饋迴路，不准先猜
codebase-design 🟣 ★深模組、小介面；「一個 adapter 是假設，兩個才是真實」
domain-modeling 🟣 ★磨利專案詞彙、即時更新 CONTEXT.md（純詞彙表）
prototype 🟣 ★拋棄式原型回答設計問題（邏輯→終端小程式；UI→多版本）
wayfinder 🔵 ★超大型工程的跨 session「作戰地圖」，只產決策不產交付
triage 🔵把四面八方的需求排成狀態機流水線，教 AI 擋不合理需求
research 🟣對照第一手來源調查，產出有引用的 Markdown
resolving-merge-conflicts 🟣逐 hunk、依「意圖」解合併衝突
improve-codebase-architecture 🔵掃描「可加深」的機會，產出視覺化 HTML 報告
ask-matt 🔵路由器：判斷你的情況該用哪個 Skill / 流程
setup-matt-pocock-skills 🔵替 repo 配置好標籤、版面、issue tracker

⚡ 生產力（productivity／5）

Skill一句話
grill-me 🔵爆紅入口：讓 AI 反問你，直到決策樹每個分支都解開
grilling 🟣 ★可複用的訪談迴路，grill-me 與 grill-with-docs 的引擎
handoff 🔵 ★把過長對話壓成交接文件，讓新視窗/子代理無縫接手（對治降智）
teach 🔵用當前目錄當有狀態的教學工作區，跨多 session 教你一項技能
writing-great-skills 🔵寫好 Skill 本身的參考：讓 Skill 可預測的詞彙與原則

✍️ 寫作（in-progress／打磨中）

Skill一句話
writing-fragments 🔵 ★探索：訪談逼問把你榨成碎片（含最值錢的 leading words）
writing-shape 🔵 ★開採：逐段把碎片塑形成一致嗓音的文章
writing-beats 🔵 ★開採：排成「選擇你的冒險」式的節拍之旅
edit-article 🔵 ★改稿：把段落當相依圖(DAG)重排、逐節重寫（personal 分類）
📌 註：repo 另有 misc/（如 setup-pre-commit、git-guardrails）與 in-progress/ 的實驗性項目（如 batch-grill-me、loop-me、wizard）。此目錄聚焦最具方法論價值的 Skill；完整清單以 repo 為準。

🚀 怎麼開始用

  • 用 Claude Code：把它當唯讀 plugin 安裝（會自動更新），或用 skills.sh 把可編輯的檔案複製進你的專案客製。之後就能打 /grill-me、/implement 等指令。
  • 不用 Claude Code：兩篇深入拆解都各附一份「手動版」流程——把這套「小步 + 先釐清 + 先測試 / 先榨碎片 + 雙軸把關」的節奏，直接搬進任何聊天型 AI 對話，就有八成威力。
💡 最小起手式：下次要 AI 做事，先禁用「幫我做 X / 幫我寫 X」，改成「先別動手，一次問我一個問題，直到你完全懂」。光這一個切換，就能砍掉大半「做出你沒要的東西」。
