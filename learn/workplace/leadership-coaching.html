⓪ 一句話總結

好主管的槓桿,不是「給出多少完美答案」,而是「啟發多少人相信自己能找出答案」。本頁把四支教練式領導主題整併成一條龍:從換掉「我來解決」的心態、學會用提問代替給答案、走一套不跳關的輔導流程、把績效當系統來設計、到把想清楚的事落地成每日習慣。

共通的一句話:把「為什麼(Why / 追責)」換成「如何(How / 下一步)」——無論是化解衝突、輔導挫折、推動績效還是溝通提案,都是同一個轉向。

這頁是什麼:四套框架的整合手冊,可從頭讀到尾當一套完整方法,也可用目錄跳到需要的段落。每個主題都有更細的深入單頁(見 ⑨ 文末)。

① 範式轉移:別當救火員 / 保姆,當教練

主管最常見的兩個慣性:反射性給解法(員工一求救就丟「多拜訪、增名單、再努力」),與盯結果審問(「為什麼沒達標?」)。方法可能正確,卻常無效——因為真正卡住員工的,往往不是方法對不對,而是他如何看待他自己。

← 左右滑動看完整圖 →
▲ 三個轉向合而為一:焦點從過去→未來、從追責→下一步、從結果→系統。不是忽視問題,而是不停在問題裡。
還有第三個慣性要破:盯數字。績效不如預期時只會問「為什麼沒達標」,如同盯著儀表板抱怨車太慢卻不掀引擎蓋。績效不是逼出來的,是設計出來的(引擎 = 習慣、內驅力、阻礙,見 ⑦)。

② 心態地基:三信念 + 教練角色

技巧沒有靈魂會變成話術。先內化教練的三個信念:

  1. 相信每個人都是有資源的。表現不如預期,不是能力不足,而是還沒找到合適的方法。
  2. 改變永遠是可能的。停止問「為什麼總做不好」,改找例外經驗:「什麼時候情況比較順利?那次你做了什麼不一樣的?」
  3. 專注在小改變上。放棄一夜脫胎換骨的期待,微小步調的累積才是長期變革的發動機。

再認清「教練」和其他角色的差別——它完全聚焦未來、目標與潛能:

角色焦點放在
心理諮商師過去的療癒與修復
培訓師 / 講師傳授特定專業技能
企業導師(Mentor)傳承自己過往的實務經驗
教練(Coach)未來、目標與潛能
核心假設 + 終極目的:員工身上早已具備解決問題的資源;主管是平等的合作夥伴,任務是把它挖出來。深度輔導真正在做的,是升級員工的「內在作業系統」——改寫他面對挫折與解讀資訊的心智程式,而不是替他解掉這一次。

▲ 實例:主管說「你這月拜訪不夠」(中性事實)→ 員工瞬間跳到「我不適合這工作」(自我否定)。教練的工作,就是把「客觀分析」這個煞車裝回去。

幫員工踩煞車的三層視角,各抓不同的東西:

層次核心提問抓什麼
① 理性論證「這想法合理嗎?有客觀事實支撐嗎?」結論對不對(近似 REBT/認知行為的觀點檢驗)
② 後設認知「我是怎麼得出這結論的?是否被情緒綁架?」思考過程哪裡漏了(系統思考、跳出來看自己)
③ 知彼解己「我是不是用自己的經驗替他揣測?他真正的顧慮是什麼?」主管自己的預設(《與成功有約》習慣五)

⑤ 說服表達:IDEAS 框架

要「說服」時,溝通無效多半不是口條差,而是開口前的思考沒結構(表達是下游、反思是上游;沒反思的「十年經驗」可能只是一年抄十次)。IDEAS 幫你在開口前把思緒打包:

← 左右滑動看完整圖 →
▲ 實戰(壽險增員):I「增員比衝個人業績更重要」→ D「增員=建可複製的組織系統」→ E「A 主任單打 5 年 ≈2500 萬 vs B 主任建團隊 ≈7500 萬,3 倍」→ A「人才槓桿/組織新陳代謝/被動收入」→ S「每週 3 次增員面談」。
金句(S 的威力):「你今天的成交決定你現在的收入,但你今天的增員決定你未來的事業。」——一個具體、可算的對比,勝過十句「這很重要」。

⑥ 輔導流程:四步驟深度教練(不可跳關)

把心態與提問接成一場實際的輔導對話。鐵律:情緒一定放最前,沒接住情緒就往下走一定失敗:

← 左右滑動看完整圖 →
▲ 這條流程對應 ③ 的三層煞車(知彼解己→理性論證→後設認知),最後收束到行動承諾。跳關的代價:直接講道理只覺得被說教;直接逼行動,承諾撐不久。
另一種視角:焦點解決的四步引導路徑——理解現狀(同理,不久留)→ 描繪願景(理想未來)→ 盤點籌碼(過往成功經驗與資源)→ 鋪設階梯(可一步步走的具體行動)。兩條流程精神一致:先安頓、再看未來、找已有資源、落到小步驟。

⑦ 績效是設計出來的:OKR × PHDI

輔導個人之外,主管還要建「績效系統」。核心公式把績效引擎拆開,讓你能像工程師一樣診斷:

← 左右滑動看完整圖 →
▲ H(好習慣)= 活動量 × 技術品質,對應主管的「活動管理」與「技術管理」;D 對應「動機管理」。阻礙 I 分四類:心理 / 能力 / 系統 / 環境,對症才能排除。

PHDI 再和 OKR 對接:OKR 定義「要達成什麼」,PHDI 解釋「績效如何形成」:

OKR 元素對應 PHDI意思
O 目標= P 績效希望創造的績效
OB 目標價值= D 內驅力賦予目標的意義
S 策略= 習慣「品質」確立執行方法
KR 關鍵成果= 習慣「數量」追蹤每天累積
CFR 對話/回饋/認可= 排除 I 阻礙定期檢視,清掉摩擦力
紅燈的正確用法:KR 進度亮紅燈只代表流程斷裂,是提問的起點、不是審判的終點。該問「遇到什麼阻礙?要不要重新設計 SOP?」——而不是「為什麼沒做到?」。內驅力靠意義感 + 約 5:1 的正向:修正回饋比例來養。

▲ 這裡的「每日習慣」正好接回 ⑦ 的 H(好習慣):想清楚只是起點,固化成習慣、靠複利累積,才變成真正的績效。

⑨ 主管的反思 / 值得偷師 / 來源

最後留一個反思:下次準備發言或與員工深談前,先問自己——「我現在只是在發出聲音,還是真正運用清晰思維在領導與賦能?」

八條可偷走的心法

  1. 把「為什麼」換成「如何」。追責只引出防衛與更多問題;問下一步才長出行動。
  2. 先處理心情,再處理事情。沒接住情緒,再正確的方法都彈回來。
  3. 相信員工有資源、找例外、專注小改變。教練的三個信念是所有技巧的靈魂。
  4. 把「客觀分析」的煞車裝回去。中性事實 ≠ 自我否定;三層煞車抓結論/過程/自己的預設。
  5. 說服用 IDEAS、辨識溝通目標。30 字主張 + 定義 + 實例 + 論證 + 意義;不是隨時都在說服。
  6. 輔導不可跳關。同理 → 檢驗 → 覺察 → 承諾。
  7. 績效是設計的:P=(H×D)−I。H、D 相乘,先減 I 常最快;紅燈是提問起點。
  8. 落到每日習慣、靠複利。GROWTH 把承諾拆成戰術與習慣;每天 1%,一年 37 倍。
