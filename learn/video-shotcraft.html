🎬 video-shotcraft:Agent 版的「程式化」產品宣傳片工作室

給 Claude Code / Codex 的開源 Agent Skill。跟它說「幫我產品做支宣傳片」,它會擷取你產品的真實頁面截圖,從一庫調過的鏡頭配方裡選鏡、分鏡,用 Remotion(React 影片框架)逐幀寫程式碼繪製,卡到節拍、加音效,逐幀自檢,交你一支可繼續編輯的 MP4。它不是用擴散模型「猜」畫面——每一幀都由程式從你自己的截圖與文案畫出,所以銳利、品牌精準、每個鏡頭可單獨改。Apache-2.0。

⓪ 一句話總結

「把 Agent 變成一座會寫程式的宣傳片工作室。」多數 AI 生影片是讓擴散模型去猜每一幀,結果字糊、品牌色跑掉、改不動。video-shotcraft 反過來:Agent 擷取你產品的真實頁面截圖,挑鏡頭、分鏡,用 Remotion 把每個鏡頭寫成一個 React 元件逐幀渲染,卡節拍、配音效、逐幀 QA,交給你一支銳利、品牌精準、每個鏡頭都能單獨改的 MP4——而且還能匯出成剪映工程讓你手動微調。

它在這份筆記裡的位置:和 Machine Skill 是同一種精神的 Agent Skill——程式化精準而非「讓模型猜」:machine-skill 用物理求解器,shotcraft 用 Remotion 逐幀繪製。GitHub Vincentwei1021/video-shotcraft,鏡頭庫 Gallery,Apache-2.0(渲染依賴 Remotion,個人與小團隊免費)。

① 不是用擴散模型猜畫面,是程式化精準渲染

核心主張就一句:It is not a video generator. 每一幀都由程式從你的截圖與文案畫出來,所以結果銳利、on-brand、完全可編輯。整條流水線是全自動的:

▲ 成片是 MP4 1920×1080 / 30fps / h264,附完整 Remotion 原始碼(每個鏡頭一個 React 元件)、2.5D 頁面運鏡/字幕/閃切/數字滾動等可複用元件、Freesound 音效搜尋下載工具與 5 條 BGM。

② 鏡頭配方卡庫與 2.5D 運鏡

它的「設計語言」沉澱成一個庫:124 張鏡頭配方卡(Shot Recipe Cards)、150 種鏡頭,分 10 類(參考了 Notion、Figma、Raycast、Linear、Perplexity 等大廠宣傳片的動效)。每張卡有它的 Remotion 實作(references/shots/<category>/<card>.md)。

例如 2.5D 頁面推拉、視窗飛入、列表捲動、數字滾動、閃切轉場、產品特寫、爆炸圖(頁面在 3D 裡傾斜拆開)、字幕隧道、聚光燈掃過……都是模組化的 TSX 範例,可以在 Gallery 直接複製鏡頭名點給 Agent 用。

③ Ink Press:現成的全自動成片模板

最快的路徑是內建的成片模板 Ink Press:把你的產品截圖、文案與 Logo 丟給 Agent,幾分鐘內就產出一支帶節奏卡點(beat sync)與電影級音效(SFX/BGM)的 MP4。模板經過驗證,是「我就想要支能用的片、別讓我選鏡」時的首選。

兩種用法光譜:一端是「用 Ink Press 模板,全自動」;另一端是「我自己點名鏡頭」——到 Gallery 複製卡名(如 deck-deal-flyin、spotlight-hero-card),叫 Agent 用這幾張卡來呈現某個功能。你要多少控制權都行。

④ Motion Workbench:瀏覽器裡的「剪映式」時間軸

成片交付後,技能會在瀏覽器開一個 CapCut 風格的時間軸編輯器(node workbench/scripts/open.mjs <project>)。影片按鏡頭、轉場、字幕、音效分軌,和當初編排的一模一樣。你可以:選任一鏡頭改文案/字號/顏色、移動/裁切/變速、把庫裡 150 個鏡頭任一個拖進來,再用 Remotion 匯出。預覽與算出來的成片逐幀一致——所以所見即所得,不會「預覽好看、匯出走樣」。

⑤ 剪映(CapCut)草稿匯出

如果你習慣在剪映裡手動微調,它能把成片匯出成可編輯的剪映工程草稿:每個鏡頭分段獨立、原生可編輯的字幕軌、分開的 BGM 與 SFX 音軌。README 說在 macOS 的剪映 Pro 11.2 上驗證過。這很關鍵——AI 給你一個起點,但最後一哩的手感調整還是回到你熟悉的剪輯軟體裡做。

⑦ 姊妹作與依賴限制

  • 姊妹作 video-talkcraft(旁白解說影片版):輸入腳本與配音,把每個動態節拍鎖定到人聲上(78 個旁白鏡頭預覽)。shotcraft 偏「卡點宣傳片」,talkcraft 偏「有人聲解說的講解片」。
  • 依賴:Node.js + npm(Remotion 渲染、模板、workbench)、ffmpeg/ffprobe(逐幀檢查與 QA)、uv(只用於 BGM 節拍分析的一次性 Python 腳本)。Remotion 首次渲染會自己下載無頭 Chrome。
  • 已知坑(README 列出):低核心機器上 --concurrency 最高 2;近期 Chrome 砍了舊 headless 模式;中國大陸可能連不上 remotion.media 的 CDN(影響自動抓 headless-shell)。主要在 macOS 測過,Linux 照註記可用。

七個帶得走的重點
