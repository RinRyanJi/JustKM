⚙️ Machine Skill:一句話,AI 幫你建出跑真物理的 3D 機械

給 Claude Code(也相容 Codex、Cursor 等支援 Agent Skills 的工具)的開源技能包。用一句話描述任何機械(渦輪扇發動機、火箭引擎、機械錶機芯、離心泵…),AI 會拆出 15~40 個具名零件(數千個實體件),賦予寫實 PBR 材質與攝影棚光影,由真實物理求解器驅動每個運動與每個數字,輸出成一個單一、無外部依賴的 .html;還能一鍵錄成 28 秒展示影片。MIT。

⓪ 一句話總結

「描述一台機械,AI 幫你建出跑著真物理的那台。」你在 Claude Code 裡打 /machine a turbofan jet engine,它會去查這台機械的真實尺寸與讓它運作的物理,建出一台 2.9m 的鈦合金風扇、10 級壓縮機、22 噴嘴的環形燃燒室……你拖油門,約 340 kN 推力是從布雷頓循環求解器算出來的,不是查表;你把它剖開,斷面是實心金屬;你丟一片扇葉,求解器告訴你機匣要扛的不平衡負載。然後一行指令把它變成一支可以 po 的影片。

它在這份筆記裡的位置:和 Crucible、OhMyGame 同屬「AI 代理 + 3D/模擬創作」一線,但 Machine Skill 是最純的 Agent Skill 形態(一個 SKILL.md 資料夾),且最強調物理正確。由 Airsup 製作(airsup.ai/lab),GitHub AirsupHQ/machine-skill,MIT。

① 一句話 → 單一自包含 HTML

輸出就是一個 .html,沒有外部依賴、沒有 build step:每頁內嵌一份執行環境 lab-kit.js(一個 ES module,從釘死版本的 CDN 載 three.js 0.170),雙擊就用瀏覽器開。

# 在 Claude Code 裡
/machine a mechanical watch movement, the escapement ticking
# → 得到 watch.html:開啟、拖曳、剖切、爆炸、弄壞它

AI 從一個 kit/template.html 起手,填四個區塊(幾何、材質、求解器、效果),把 lab-kit.js inline 進去。因為是單檔,分享、嵌入、歸檔都只是一個檔案的事。

② 不是動畫,是「真實物理求解器」驅動

這是它和「AI 生 3D 動畫」最根本的差別:畫面上每個數字、每個運動,都是一個小求解器算出來的,不是預先編好的動畫曲線。技能包帶一份 references/solvers.md,收了各類機械的真實物理方程式與常數。

← 左右滑動看完整圖 →
▲ 每台機械配一個小求解器(氣渦輪、火箭、活塞、手錶、轉子、泵、工具機、多孔流、電機…)。拖滑桿 → 求解 → 數字與運動一起變,還能按「How it is computed」看方程式。

例子:火箭引擎(Raptor 式全流量)在 330 bar、海平面解出 2,462 kN、Isp 321s、噴口 Mach 4.06;剖開切斷再生冷卻,銅喉就熔化。離心泵則跑泵浦曲線 + 親和律、BEP、NPSH 可用 vs 需求。

③ 真實零件 · 材質 · 攝影棚

面向做到什麼
真實機械以公尺為單位的真實比例,15~40 個具名零件、數千個實體件(葉片/齒/螺栓),車削實體、彎扭翼型、漸開線齒輪、走線管路;有比例尺顯示真實大小
真實材質物理基 PBR:鋼、鈦、Inconel、銅、黃銅、鋁、漆、聚合物、玻璃、藍寶石,帶量測反射率、微表面(車紋/拉絲/鑄面)、清漆,以及由求解器溫度算出的熱發光
攝影棚柔光箱環境 + 黑旗、軟 key 陰影、接觸陰影、AO、bloom、無縫背景或夜景——動起來前先像一張產品攝影
剖面(cutaway)怎麼做的:每個零件都是被兩個平面裁切的封閉實體;當平面切開實體,相機看到的是背面——材質的 shader 用視線對兩平面投射認出它們,把背面畫成斷面(寫入深度緩衝正確遮擋、新切削的同材質顏色 + 淡陰影線)。沒有補蓋幾何、任意切位,所以切面能即時掃動。

④ 互動模式與「弄壞它」

每台機械都附一組模式:爆炸圖(explode)、剖面(cutaway,實心斷面)、X 光(x-ray)、慢動作、即時標籤、暫停,以及最有意思的 computed "break it"——用求解器算出來的故障。

  • 渦輪扇:丟一片扇葉 → 求解器算機匣要扛的不平衡負載。
  • 火箭:切斷再生冷卻 → 銅喉過熱熔化。
  • 離心泵:降低塔液位 → 汽蝕(cavitation)。
  • 壓縮機:防喘振閥卡住 + 下游跳機 → 喘振(surge)。

這些不是播放一段「壞掉動畫」,而是把故障條件餵進同一個求解器,讓它算出後果——所以你調的參數會真的改變故障的樣子。

⑤ 四輪自我審查 + 一鍵錄影

生成不是一次就交。SKILL.md 的工作流裡有四輪 critic(自我審查):用 scripts/shot.mjs 自動截圖、印出 FPS/零件數/三角形數,讓 Agent 檢查零件遮擋、比例、幾何問題再修。通過後,一行錄成影片:

node scripts/record.mjs examples/turbofan.html out/feed.mp4 --w 1080 --h 1350   # 直式

⑥ 怎麼用與安裝

# 安裝(skills CLI,全域)
npx skills add AirsupHQ/machine-skill -g -a claude-code    # → ~/.claude/skills/machine
# 或 git clone 到 ~/.claude/skills/machine
/machine a hydroelectric Francis turbine
/machine a Swiss lever escapement, slowed down so I can see the impulse
/machine a steam locomotive's valve gear, and give me a 30 second video for X

三個拿到好結果的習慣:點名真實的東西(「像 787 上的那種渦輪扇」勝過「一個噴射引擎」)、說清楚什麼該動、什麼該壞(「轉到氣門浮動」告訴求解器要算什麼)、說它要去哪(嵌網頁、X 的影片、投影片的靜圖)。需求:Claude Code(或任何 Agent Skills host)、支援 WebGL2 的瀏覽器;錄影需 Node 18+、Playwright、ffmpeg。其他 host(Claude.ai、Codex、Cursor)指向 SKILL.md 即可。

⑦ 限制:一個誠實的小模型

  • 它建的是「機械」:機構、引擎、儀器、裝置。人、地景、地圖做出來較弱。
  • 物理是誠實的小模型,不是 CFD/FEA:每頁都寫明它算了什麼、簡化了什麼;數字對照公開資料,但未經認證。
  • 是真實零件,不是 CAD 匯出:幾何是程序化 three.js,比例與零件數準確,但不到製造公差。
  • 重的頁要像樣的 GPU:約 60 萬三角形 + 陰影/AO/bloom 在近期筆電上約 60fps。
為什麼這些限制反而是優點:它不假裝自己是工程級模擬,而是把「教學/展示級的物理直覺」做到位又好看。對理解一台機械怎麼運作、做簡報、做內容,這個「誠實的小模型」剛剛好。

⑧ 重點 · 關聯 · 來源

七個帶得走的重點

  1. 一句話 /machine ... → AI 建出單一自包含 HTML 的 3D 機械模擬(three.js,無 build)。
  2. 真物理求解器驅動:推力/溫度/壓力/扭矩是算出來的,不是查表或編動畫。
  3. 15~40 具名零件 + 數千實體件 + PBR 材質 + 攝影棚光影 + 熱發光。
  4. 模式:爆炸/剖面(實心斷面 shader)/X 光/慢動作/標籤,以及算出來的「弄壞它」。
  5. 四輪自我審查(shot.mjs 截圖檢查)+ record.mjs 一鍵錄 28s 影片(確定性時鐘)。
  6. 標準 Agent Skill(一個 SKILL.md 資料夾);npx skills add 即裝。
  7. 誠實標限制:小模型非 CFD/FEA、程序化非 CAD;MIT。姊妹作 Factory skill。
