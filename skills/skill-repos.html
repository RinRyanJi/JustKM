① 怎麼看這 10 個 repo

這 10 個 repo 可分成三種角色，需求不同就看不同類：

類型repo你什麼時候看它
官方廠商出品anthropics · google · dotnet · github/awesome-copilot要那家平台/語言的權威做法時
個人/團隊精選技能包addyosmani · obra/superpowers · mattpocock · CommandCodeAI要一整套可直接裝來用的工程工作流時
Awesome 精選清單VoltAgent · skillmatic-ai要找還有哪些 skill / 資源的索引時
關於數字：各 repo 的 star 數在自動摘要中常失真，本頁刻意不列 star 數；熱度請以 GitHub 現況為準。安裝第三方 skill 前，務必先看過內容再裝。

② anthropics/skills

官方 · AnthropicApache 2.0（文件類為 source-available）GitHub ↗

定位：Anthropic 官方的 Agent Skills 示範庫——教你怎麼替 Claude 建立與使用 Skill，也是 agentskills.io 開放標準的參考實作。附 spec/ 規範與 template/ 範本。

收錄的 skills

  • 📄 Document Skills：docx、pdf、pptx、xlsx（source-available，作參考）
  • 🎯 Example Skills：創意與設計、開發與技術、企業與溝通三大類示範

怎麼用：/plugin marketplace add anthropics/skills → 安裝 document-skills / example-skills；也可在 Claude.ai 上傳自訂 Skill、或走 Skills API。

這是「想懂 Skill 到底長怎樣」的第一站——JustKM 本站用到的 docx/pdf/pptx/xlsx 就是這一脈。

③ google/skills

官方 · GoogleApache 2.0GitHub ↗

定位：Google 官方、聚焦 Google Cloud 與 Google 產品的 skill 集合（開發中）。幾乎是把「怎麼正確操作 GCP」做成一條條可觸發的工作流。

主要分類

  • 基礎設施（最大宗）：GKE 叢集建立/升級/工作負載、儲存、網路、安全、自動擴展、TPU 監控、Cloud Storage、負載平衡
  • AI/ML：Agent Platform（部署/微調/RAG 引擎/提示管理）、Gemini API、BigQuery AI/ML、模型註冊與評估
  • 資料庫：AlloyDB、BigQuery、Bigtable、Cloud SQL、Spanner、資料譜系
  • 管理/治理：Cloud Monitoring/Logging、成本分析、SLO 告警、Well-Architected（成本/營運/效能/可靠/安全/永續）
  • 其他：gcloud CLI、Cloud Run / Firebase、Google Ads、Google Analytics

怎麼用：npx skills add google/skills，或透過 Claude/Codex 的 plugin marketplace。

⑤ github/awesome-copilot

官方 · GitHub 社群MIT（內容來自第三方）GitHub ↗

定位：GitHub 官方維護的 Copilot 客製化市集——不只 skills，而是一整套增強 Copilot 的資源。

收錄的內容類型

類型是什麼
Agents整合 MCP server 的專用 Copilot 代理
Instructions依檔案模式自動套用的編碼規範
Skills自帶指令與資源的技能資料夾
Plugins針對特定工作流打包的 agents + skills
Cookbook操作 Copilot API 的即用食譜

怎麼用：copilot plugin install <name>@awesome-copilot（marketplace 多半已預先註冊）。

注意：官方明講內容來自第三方開發者，安裝前請先檢視 agent 與其文件。

⑥ addyosmani/agent-skills

精選技能包 · Addy Osmani 等MITGitHub ↗

定位：把「資深工程師的工作流、品質關卡、最佳實踐」編成 24 個生產級技能，涵蓋完整開發生命週期六階段。支援 70+ 種 agent。

六階段技能

  • Define：interview-me（需求訪談到 95% 信心）、idea-refine、spec-driven-development
  • Plan：planning-and-task-breakdown（拆成可驗證小任務）
  • Build：incremental-implementation、test-driven-development、context-engineering、source-driven-development、doubt-driven-development、frontend-ui-engineering、api-and-interface-design
  • Verify：browser-testing-with-devtools、debugging-and-error-recovery
  • Review：code-review-and-quality、code-simplification、security-and-hardening、performance-optimization
  • Ship：git-workflow-and-versioning、ci-cd-and-automation、deprecation-and-migration、documentation-and-adrs、observability-and-instrumentation、shipping-and-launch
  • Meta：using-agent-skills（把任務對應到正確技能）

怎麼用：npx skills add addyosmani/agent-skills（Claude Code 可市集安裝；Cursor/Copilot/Gemini CLI 等各有設定法）。

⑩ 兩份 Awesome 精選清單

VoltAgent/awesome-agent-skills

Awesome 清單 · 社群GitHub ↗

收錄 1,497+ 個 agent skill，主打「真實工程團隊在用的，不是大量 AI 生成的湊數貨」。分類含：官方 Claude skills、測試自動化（Playwright/Cypress/Selenium/Jest 等 50+）、雲平台（Azure/Cloudflare/Netlify/Vercel）、AI/ML（Hugging Face/Replicate/fal.ai/Gemini）、前端（Next.js/React Native/Angular/WordPress）、安全（Trail of Bits）、行銷（Corey Haines）。貢獻者含 Anthropic、Google、Vercel、Stripe、Microsoft 等。

skillmatic-ai/awesome-agent-skills

Awesome 清單 · 社群CC0-1.0GitHub ↗

比較偏「學習與生態索引」的清單，四大區塊：① 基礎概念（文章/影片/課程）、② 現有技能使用（支援平台、技能庫、市集目錄如 SkillsMP/agentskill.sh/Skillstore）、③ 構建與整合（開發指南、工具、框架）、④ 基準與研究（評估框架、論文）。強調 Skill＝模組化 SKILL.md、漸進揭露。

兩份差異：VoltAgent 偏「skill 本身的大目錄」（找可用的技能）；skillmatic-ai 偏「學習與資源地圖」（了解生態、找教材與市集）。

⑪ 怎麼安裝與選用

多數 repo 走兩條安裝路徑之一：

# 通用 CLI（跨多種 agent）
npx skills add <owner>/<repo>

# Claude Code 市集
/plugin marketplace add <owner>/<repo>
/plugin install <plugin-name>

# GitHub Copilot
copilot plugin install <name>@awesome-copilot

選用建議

  • 想懂 Skill 原理與範本 → anthropics/skills
  • 要一整套工程工作流 → addyosmani/agent-skills（生命週期最完整）、obra/superpowers（方法論紀律）、mattpocock/skills（對齊/架構最實戰）
  • 綁特定平台 → google/skills（GCP）、dotnet/skills（.NET）、github/awesome-copilot（Copilot）
  • 要廣度、找更多 → 兩份 Awesome 清單
安全提醒：Skill 會被 agent 當指令執行。安裝任何第三方 skill 前，先讀過 SKILL.md 與其腳本，確認沒有非預期的動作或外洩。
